Character path:
- 0x468D40 resolves selection through page state at object+0xEC and table 0x64C81B + page*0x25 + selection.
- selection 0x25 is remapped to table slot 0x24.
- 0x4692B1..0x4692E3 handles selections below 0x26 and appends one byte to object+0x5F4.
- current/minimum/maximum lengths are WORD fields at object+0x6F6/+0x6F8/+0x6FA.

Control path:
- 0x26 BACKSPACE: decrements current length and clears the trailing byte.
- 0x27 toggles page 1 / page 2.
- 0x28 toggles page 1 / page 3; page 3 returns to page 1 after one appended character.
- 0x29 toggles page 1 / page 4; page 4 persists.
- 0x2A toggles page 1 / page 5.
- 0x2B END/confirm: checks current string length against the minimum, sets completion state/result, then finalizes.

Five 37-byte page mappings:
- page1: digits 1-0, lowercase a-z, space.
- page2: punctuation/symbol and legacy high-byte glyph codes, ending in space.
- page3: digits 1-0, uppercase A-Z, space; one-shot behavior.
- page4: digits 1-0, uppercase A-Z, space; persistent behavior.
- page5: digits 1-0, legacy extended-byte glyph codes, space.
