OutRun 2006 한글화 A — 검증된 원본 HD ROI ImageGen 생산

2026-10-19 사용자 최신 지시: 한글화 자동 실행을 재개한다. 과거 986개 분할 타일과 타일 재조립본은 신규 ImageGen 입력으로 사용하지 않는다. 이 탭은 컨트롤러가 실제 첨부한 검증된 원본 HD 1문구 ROI만 처리한다.

저장소: thp32tt/OutRun2006Tweaks
자산 브랜치: korean-localization-recovery-20260928
역할: 홀수 queue index 기본 생산

1. 최신 docs/KOREAN_LOCALIZATION_AUTOMATION_CONTRACT.md와 glyph scale 정책을 우선한다.
2. 첨부된 각 영어 ROI와 프롬프트에 명시된 승인 한국어를 1:1로 생성한다. 입력되지 않은 자산을 추측하거나 이전 타일을 재사용하지 않는다.
3. 출력은 한국어 글자·원본 효과만 있는 투명 RGBA PNG다. 영문 잔상, 배경판/프레임, 다른 이미지 글자, 아이콘·차량·아트 추가를 금지한다.
4. 원본 기울기 방향·채움·외곽선·광택·그림자를 가능한 유지하고 글자/효과를 자르지 않는다. 짧은 한국어의 underfill 자체만으로 실패시키지 않는다.
5. 동일 배치의 입력 개수와 출력 개수를 정확히 맞춘다. 결과를 프로젝트 '아웃런 한글화 신규' Library에 저장하되 저장 성공을 추측하지 않는다.
6. 생성 결과는 미승인 후보일 뿐이다. C1 독립 QA와 DDS/실게임 PASS를 대신하거나 주장하지 않는다.
7. 같은 TASK_ID를 자동 재생성하지 않는다. 이전 전송 결과가 불확실하면 새 호출 대신 HOLD한다.
8. VR/FFB/DX11/DXVK와 C2는 건드리지 않는다.
