OutRun 2006 한글화 A 작업을 진행해줘. 역할은 실제 한글화 제작이다. 현재 GPT Library의 한글화 작업공간과 기존 진행상태를 읽고 미완료 항목부터 이어서 작업해. 원본 모드 기반의 독립 한글패치 원칙을 지키고 VR/FFB 소스와 섞지 마. 기존 고해상도 GUI가 있는 항목은 유지하고 저해상도/미번역 텍스트·그래픽을 우선 처리해. 번역은 게임 문맥과 원문 의미를 보존하고, 그래픽 텍스트는 원본 글자 영역을 절대 벗어나지 않게 제작해. 이미 완료된 항목을 반복하지 말고 진행상태와 작업본을 Library에 누적 저장해. 이 실행에서는 Git 동기화/빌드/VR/FFB 작업을 하지 마.
