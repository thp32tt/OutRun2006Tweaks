공통 강제 규칙: 작업 시작 전에 korean-localization-clean의 docs/KOREAN_LOCALIZATION.md, localization/WORKLOG.md, localization/progress.json, localization/resume_state.json, localization/graphics/README.md, localization/graphics/ORIENTATION_POLICY.md와 현재 진행상태를 읽고 그 규칙을 우선 적용해. 특히 (1) HD 모드 DDS가 있으면 그것이 그래픽 제작 기준이며 기존 저해상도 한글 DDS 업스케일 금지, (2) 원본/HD DDS의 실제 header 기준 dimensions·format·alpha·mips 보존, (3) 원본 raw DDS의 sprite별 mirror/rotation 방향 그대로 유지, (4) 차량명·모델명·브랜드/로고·곡명/크레딧·법적 표시는 원본 보존, (5) 원본 배경/비텍스트 artwork 최대 보존, (6) 한글의 새 비투명 픽셀은 원본 text region/sprite cell을 절대 벗어나지 않으며 잘림·겹침도 금지, 맞지 않으면 축소/짧은 번역/원본 유지, (7) 원본과 유사한 색·outline·shadow·gradient·비율·정렬 등 style fidelity 유지, (8) 검은 선·seam·잔상·opaque box·alpha halo 등 편집 artifact가 있으면 reject/rework, (9) 완료된 항목 반복 금지 및 현재 resume/progress부터 계속, (10) 각 완료 batch마다 machine-readable report, WORKLOG, localization/progress/STATUS.md를 갱신, (11) VR/FFB source/history merge 금지, (12) 승인 전 raw DDS와 readable/game orientation 양쪽 QA 및 가능한 경우 in-game screenshot validation을 통과해야 해.

Git 동기화는 이 역할의 필수 종료 단계다. 작업 시작 시 korean-localization-clean 최신 HEAD를 확인하고, 작업 완료 후 이번 역할에서 실제 변경한 한글화 파일·보고서·진행상태만 같은 브랜치에 commit/push해. push 성공과 최종 commit SHA를 확인해야 이 실행을 완료로 간주해. 충돌이 있으면 원격 최신 상태를 다시 확인해 기존 A/B/C/D 결과를 보존하면서 해결하고, VR/FFB 변경을 끌어오거나 다른 브랜치로 우회하지 마. 변경사항이 전혀 없으면 빈 커밋을 만들지 말고 현재 HEAD와 no-change를 기록해.

픽셀 경계 전수검사 강제 규칙: 실제 게임에서의 글자 잘림을 막기 위해 이번 역할이 다루는 신규/수정/기존 승인후보 그래픽 전체를 원본 또는 해당 HD 기준본과 1:1로 검사해. 각 텍스트 요소별 원본의 실제 비투명 텍스트 픽셀 bounding box와 해당 sprite cell/허용 text region을 산출하고 수정본의 새 한글 비투명 픽셀 bounding box를 비교해. 수정본이 원본 텍스트 bounding box보다 좌/우/상/하 어느 방향이든 단 1픽셀이라도 더 크거나 원본 sprite cell/text region을 1픽셀이라도 벗어나면 FAIL로 처리하고 즉시 축소·재배치·문구 단축 후 다시 검사해. 캔버스/DDS 전체 dimensions가 같다는 이유로 통과시키지 마. outline·shadow·glow·alpha fringe도 비투명 픽셀 범위에 포함해 검사하고, raw DDS orientation과 실제 게임 표시 orientation 양쪽에서 동일하게 확인해. 전수검사 결과는 asset별 original_bbox, localized_bbox, delta_left/right/top/bottom, containment PASS/FAIL 및 재작업 여부를 machine-readable report에 남겨. 기존 approved_dds도 예외 없이 이 기준으로 재검사하고 FAIL이면 승인에서 제외해 재작업해.\n3단계 운영 역할: A(:00)는 실제 제작 담당이다. 미완료 제작을 진행하되 제작 직후 위 픽셀 경계 검사를 수행하고 실패 항목은 같은 실행에서 재작업한다.
