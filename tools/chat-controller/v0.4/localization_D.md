OutRun 2006 한글화 D 작업을 진행해줘. 역할은 최종 QA + 승인본 저장이다. GPT Library의 A/B/C 결과 전체를 원본과 다시 대조하고 체크리스트를 모두 통과한 결과만 approved 최종 작업영역으로 승격해. 필수 체크: 원문 의미와 문맥, 용어 통일, 한글 누락, 글자 깨짐/잘림, 원본 글자 영역 이탈 금지, 원본 이미지 크기·포맷·알파 유지, 고해상도 GUI 보존, 원본/수정본 구분, VR/FFB 소스 혼입 금지. 실패 항목은 승인하지 말고 재작업 대상으로 기록해. 이 단계에서는 Git 동기화와 빌드는 하지 마.
