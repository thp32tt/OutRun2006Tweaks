첫 작업: GitHub 최신 docs/KOREAN_LOCALIZATION_AUTOMATION_CONTRACT.md 및 docs/KOREAN_LOCALIZATION_HD_PNG_IMAGEGEN_AND_FAST_QA_20261012.md 읽기. 최신 원본 HD DDS SHA/헤더/방향/원본 UI 칸 좌표와 번역 manifest를 확인. 정방향 PNG를 ChatGPT composer에 실제 첨부해 썸네일 검증 후 내장 이미지 생성 기능으로 영문/일문만 한글 변환. 큰 atlas 전체 입력 가능, 필요시 HD 원본 crop 입력. 생성된 문구만 원본 UI 칸 안에 종횡비 유지 크기/XY 위치 보정하고 CLEAN 합성, 차량·로고·음악 제목·아이콘 보존, 원본 DDS 형식/방향으로 저장. 실제 저장 DDS에서 한글 깨짐·오자·잘림·칸 초과·겹침·원본 보호 픽셀 훼손/형식 오류만 엄격 QA. 미세 색/광택/서체/여백 차이 허용. C1 batch QA와 실게임 테스트는 독립, C2 없음. 실게임 미실행 UNTESTED, legacy C2 PASS 위조 금지. 작업물/상태는 같은 브랜치 commit/push, HEAD 검증. VR/FFB/DX11/DXVK 제외.

수동 배포 정책: GitHub 결과/정책만 반영한다. Docker/Portainer 배포·재시작, AUTO_SEND 활성화, 게임 폴더 설치·정식 릴리스는 사용자가 수행한다. 새 큐 생성·기존 결과 초기화 금지.
생성 전문은 tools/localization/imagegen_prompts/의 atlas/roi 템플릿과 build_imagegen_prompt.py로 승인 번역표를 치환하여 보관한다. 프롬프트 조립 성공은 실제 첨부/생성 성공이 아니다. 전체 atlas는 대상들이 동일 READABLE 변환일 때 기본 입력; 서로 다른 방향이면 문구별 정방향 crop으로 전환한다. 지원되는 직접 이미지 편집 도구의 실제 파일 입력도 유효하며 composer만 강제하지 않는다. 첨부/출력 바이트 미확인 상태에서 생성 성공을 기록하지 않는다. 전체 결과를 DDS에 덮어쓰지 말고 글자층을 추출해 원본에 합성한다. 동일 원인의 생성 실패는 2회까지, 이후 문제 ROI만 수정하거나 HOLD 후 다음 독립 자산을 진행한다. C1 독립 CLEAN 검토를 재사용하고 퇴역 C2 검수를 새로 요청하지 않는다. 유료 API/옛 자동 폰트 렌더러로 무단 전환 금지.
