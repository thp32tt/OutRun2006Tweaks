첨부한 OutRun 2006 영문 원본 UI 텍스처를 ChatGPT 내장 이미지 생성 기능으로 편집해 실제 결과 이미지 1장을 만들어줘. 설명이나 코드만 출력하지 말고 이미지 생성을 실행해줘.
2048×2048 전체 캔버스, 투명 배경, 전체 레이아웃과 방향을 유지해.
START는 정확히 '출발', GOAL은 정확히 '골'로 변경해. 다른 문구는 수정하지 마.
원본 색, 획, 광택, 테두리, 그림자, 기울기 방향과 위치를 최대한 유지해. 한글은 각 글자가 정확히 읽혀야 하며 실제 UI 칸 밖으로 나가거나 겹치거나 잘리면 안 돼. 문장 폭을 맞추려고 가로로 늘이지 마.
OutRun2SP 로고, 지도, 경로, 코스 썸네일, 자동차, 배지 및 모든 비텍스트 아트를 보존해. 새로운 장식, 번호, 사각 배경을 만들지 마.
이것은 신규 A 슬롯 단건 시험이며 과거 생산물·QA를 승계하지 않는다. 유료 API, Python 글자 제작을 대체 생산 수단으로 사용하지 마.
