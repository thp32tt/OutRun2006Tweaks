# OutRun 2006 VR — 2026-09-21 통합 테스트 시나리오

대상은 **D3D9Ex REFERENCE + CORRECTNESS** 1회입니다. 이번 빌드는 오늘 확인된 렌더링·HUD·로그 신뢰성 변경을 한 번에 검증합니다.

## 준비

1. 게임과 `outrun-vr-host.exe`를 모두 종료합니다.
2. 테스트 ZIP의 파일을 OutRun 2006 게임 폴더에 덮어씁니다.
3. Virtual Desktop/VDXR과 Quest 3의 평소 주사율(72/80/90Hz 중 사용 중인 값)을 그대로 사용합니다. 임의로 120Hz로 바꾸지 않습니다.
4. `OutRunVR-Backend-Selector.cmd`를 실행합니다.
5. **D3D9Ex REFERENCE**와 **CORRECTNESS**를 선택하고 **Start VR Test**로 실행합니다. 직접 명령어를 입력할 필요는 없습니다.

## 1. 메뉴 / 차량 선택

- 메인 메뉴에서 고개를 좌우·상하로 움직입니다.
- 메뉴가 머리에 붙어서 따라오거나 좌우 눈에서 갈라지지 않는지 봅니다.
- 차량 선택 화면의 3D 차량 모델이 깨지거나 한쪽 눈에서 사라지지 않는지 봅니다.
- 메뉴에서 F12 리센터를 한 번 누르고 화면 소실/이전 로딩화면 고정/검은 화면이 발생하는지 확인합니다.
- 종료 YES/NO 화면까지 한 번 들어갔다가 취소하여 글자 위치와 양안 정렬을 봅니다.

## 2. 게임 플레이

짧은 OutRun 또는 Mission 구간으로 충분합니다.

- HUD의 **순위, 점수, 6th/6, 시간**이 화면 안에 있고 두 눈에서 하나로 합쳐지는지 확인합니다.
- 상대 차량 위 순위/마커가 머리를 따라오지 않고 해당 차량과 함께 움직이는지 확인합니다.
- 하늘/구름/스카이박스가 머리를 따라오지 않는지 확인합니다.
- SkyGlowFactor=1 상태에서 glow가 보이며 좌우 눈에 서로 다른 잔상/유령상이 생기지 않는지 확인합니다.
- 렌즈플레어, 연기, 스키드마크 위치가 월드와 함께 움직이는지 확인합니다.
- 직선과 코너에서 프레임 페이싱을 보고, 이전처럼 HMD에서만 심한 반토막/버벅임이 있는지 확인합니다.
- 게임 중 F12 리센터를 한 번 실행해 검은 화면이나 마지막 로딩화면 고정이 없는지 확인합니다.

## 3. 전환 / 종료

- 일시정지 → 게임 복귀를 한 번 수행합니다.
- Goal/Result 또는 메뉴 복귀까지 진행합니다.
- YES/NO 종료 화면에서 좌우 눈 정렬을 다시 확인한 뒤 정상 종료합니다.
- 게임 종료 후 런처가 로그 수집을 마치도록 두고 생성된 `OutRun2_VR_ANALYZE_*.zip`만 업로드합니다. 별도 설명은 없어도 됩니다.

## 우선 판정 항목

`TEST_RESULT.txt`에는 특히 다음을 기록하면 됩니다: FPS/HMD_SMOOTHNESS, STEREO, RECENTER, HUD_RANK_SCORE, SKY_CLOUD, SMOKE_SKID, MENU_CAR, EXIT_YES_NO.

주요 실패가 하나라도 있으면 추가 PERFORMANCE/CONTROL 테스트를 반복하지 말고 **첫 CORRECTNESS 로그 ZIP**을 먼저 분석합니다. 이번 테스트의 목적은 여러 빌드를 반복 실행하는 것이 아니라, 한 번의 런타임 증거로 다음 수정 대상을 좁히는 것입니다.
