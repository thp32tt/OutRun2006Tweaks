## Conditional source optimization choices (implement only after attribution)
**A. CPU classify/state reads** — R33/R29: reuse one per-logical-Draw state snapshot and proven classification, only for setter/StateBlock tracked fields. Fence cache by device/resource generation and setter serial, invalidate on relevant state/shader/FVF/RT/DS/stateblock/Reset/loss transitions; unknown state uses live read/fail-closed route. Repair only demonstrated excess fallback; never set fragile=false globally or force zero disparity. Evidence: fewer duplicate reads/fallbacks and lower CPU p95.

**B. Confirmed XYZRHW UP transport cost** — R30 only when glass/effect truly uses it: preserve CPU per-eye maths; use reusable DEFAULT-pool dynamic WRITEONLY VB/IB, NOOVERWRITE until capacity then DISCARD only safe untouched ring range. Prepare both eyes prior to GPU submit; do not DISCARD eye 1 before eye 2. If Lock/allocation fails, fall back **before** first-eye Draw; never replay after partial output. Preserve min/index/baseVertex/stride/topology, 16/32-bit indices and UP versus VB state side-effects, StateBlock, Reset and reentrancy. Measure UP calls/bytes/CPU and reject if small-Draw Lock costs worsen frame pacing.

**C. Confirmed per-Draw stereo RT churn** — R30: batch only verified adjacent producer group with per-eye alpha order preserved. Flush at RT/DS/Clear/query/stencil/StateBlock, unknown owner, or observable API/HRESULT boundary. No global left-all then right-all reorder; ensure replay state/lifetime and net RT savings.

**D. Confirmed GPU glass/reflection bottleneck** — identify real shader/material/pass. Count necessary per-eye reflection/stencil/depth and remove only demonstrably redundant rendering; verify blend equation, fog/color space, different eye inputs. Reuse only eye-independent reflection producer passes. Reduction of reflection rate/resolution must be separately labeled a **quality tradeoff**, never same-quality speedup.

**E. Confirmed smoke/dust overdraw** — consider depth-aware reduced-resolution particle RT only for proven smoke/dust producer, assess D3D9Ex MSAA/depth/extra pass overhead; do not apply to glass/water/HUD/flare generically.
