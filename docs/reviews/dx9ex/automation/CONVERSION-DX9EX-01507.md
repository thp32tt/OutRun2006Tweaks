## REVIEW_SCOPE — GOAL producer -> semantic -> partial/full queue -> native GPU -> R30/R62 -> L/R -> restore -> Present/OpenXR

1. The two proven original full-result graph calls at RVA 0x98924 and 0x992AC target 0x979E0. The installed Call replacements invoke `ResultProgressFullParent`. The separate 0x97BE4/0x97DEC inner fill E8 midhooks and B9200 function-entry glyph wrapper are different paths; this audit is for graph background/other sibling nodes not necessarily owned by either nested source.
2. `ResultProgressFullParent` checks `VREnabled`, `STATE_GOAL` and `!QueueRenderActive()` at entry. It Flushes any proven outgoing direct GOAL batch, snapshots every priority's root/tail and a semantic registry **serial**, then scopes direct `ScreenHud/ResultProgress` across `original()`.
3. When `original()` returns, the only publication check is `VREnabled && STATE_GOAL`. The wrapper does **not** save/check `SpriteQueueNodeEpoch`, queue depth on return, whether any partial/full queue pass began, or which of the parent-produced nodes was already physically consumed before `TagAppendedNodes`. It calls `TagAppendedNodes(before,...,ResultProgress,...,&rootsBefore,entrySerial,true)` and source-exit D3DX Flush.
4. `TagAppendedNodes` validates a bounded current root -> oldTail -> terminal newTail chain (for this special full parent) and protects later already-exact *different* producers via `entrySerial`. Neither a stable chain nor that registry serial is a negative proof that physical queue selection/consumption has **not already happened** during `original()`.
5. `SelectSpriteQueueNode` lazily begins a pass and snapshots `SpriteQueueSemanticCutoff=NextSerial-1`; each node increments `SpriteQueueNodeEpoch`, consumes any eligible pre-existing tag, and otherwise uses generic `ScreenOverlay2D`. A tag published after the cutoff is excluded from that active pass. `EndSpriteQueueRender` explicitly retains unvisited tags for a possible later partial/full pass, and `EndSpriteQueueFrame` retires remaining tags only at Present/reset boundaries.
6. **Source-conditional schedule, not a real observed frame:** VR stays true and mode stays GOAL. Parent enters outside queue with old tail A; `original()` appends previously untagged full-graph sibling G (not the inner fill E8). Before parent returns, a nested original partial pass selects G while its tag has not yet been published (generic 2D queue semantic), finishes, and the live bounded root/tail A->G remains intact. Parent returns, passes its VR/mode checks and publishes `ResultProgress` for G **after its first physical consumption**; any later eligible queue selection of G can acquire the finite result HUD semantic instead. This is a conditional *within-result temporal semantic split*, not a guaranteed duplicate draw or crash.
7. If a queue is still open at parent return, the tag's new registry serial is above that pass's captured cutoff, so it cannot retroactively fix the GPU draw already in flight; a later independent pass with a fresh cutoff may see it. If the original graph never invokes queue rendering before returning, the implementation's normal deferred tagging remains correct. A root change without a reachable old tail, removed G, no new tail, expired frame, or newer different exact nested tag can eliminate the scenario.

In the archived original EXE queue, 0x449050 -> 0x42D710 dispatches type0 D3DX (0x42A0A0, possible Flush/End delay), direct-UP (0x42C0F0), type1 animation (0x42A3A0) and masked/composite (0x42A800). The early consumption may have already issued a native GPU call or only buffered D3DX commands; these are different physical timings. This audit does not assert all arms reach R62.

R33's native dispatch and R62 R26-safe FVF=0x142, live VS=null, target, pose/projection/eye-resource gates must independently succeed before LEFT and RIGHT raw draws. RIGHT RT/depth/viewport and original projection restoration have separate failure states; R7 only publishes a fresh SBS/DirectGPU frame if world+duplicated pose/resource proof exists without right/incomplete failure. The x64 OpenXR final image and real Quest3 outcome are not measured.
10. Existing comments about partial->full queue preservation explain why `EndSpriteQueueRender` intentionally does not indiscriminately clear unvisited tags. The missing parent-specific queue-pass admission proof cannot be fixed by a global registry clear. The old user log has no same-SHA DLL/host and no synchronized parent->queue->GPU evidence.
