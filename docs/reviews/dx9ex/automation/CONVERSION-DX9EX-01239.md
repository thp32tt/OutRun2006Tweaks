## REVIEW_SCOPE

After 01238's **partial scissor/per-eye clipping** audit, review the *different* state and execution boundary: original masked/composite type-1 SpriteNode (0x42A800) versus ordinary type-1 (0x42A3A0) -> producer/queue epoch/possible pending one-shot -> D3DX batch or direct native GPU command (not yet mapped for any particular mask) -> physical DP/DIP/DPUP/DIPUP live COLORWRITE/ZWRITE/STENCIL/ALPHATEST/ALPHABLEND state -> R26 active-occlusion-query write-free single-execution or normal R23/R22 replay -> optional R30/R62 verified stereo HUD owner -> L/R RT/depth/stencil/viewport and original state restore -> R9 Present -> host actual xrEndFrame. The question is whether a mask's *write-bearing pass* could be mistaken for an invisible query proxy, **not** whether 01238's scissor is eye-shifted. Original masked branch does not itself establish an active occlusion query, final physical API, state values, draw count, or an HMD defect.
