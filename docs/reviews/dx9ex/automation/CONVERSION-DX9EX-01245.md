This is a conditional *work eligibility* observation, not a measured occurrence.

Therefore any shadow GPU work performed while gap stays true is ineligible for the normal Present fallback copy, absent later reseeding/recovery. It does NOT follow that the fallback image is necessarily visually wrong.
7. `vrhost/src/main_r23.cpp:3562-3617` verifies real xrEndFrame layer/frame identity independently of game Draw/Present. Previous `01244` analyzed *post-eye projection restore HRESULT asymmetry*; `01243` analyzed *left-eye SetTransform failing before DIP*; `01239` analyzed *occlusion write-free single execution*; `01226` covered D3DX *device lifecycle* callbacks. This review instead isolates the **R9 backup-gap veto missing from shadow replay, and the R13 forced-shadow gate ordering**. GitHub source does not provide Quest3 HMD/fps evidence.
