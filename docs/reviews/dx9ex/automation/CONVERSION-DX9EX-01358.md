## CONDITIONAL PRODUCER -> SEMANTIC -> QUEUE -> GPU -> L/R -> PRESENT/OPENXR

1. **Original producer is not one draw family.** The checked-in SHA-pinned original EXE disassembly places `sub_40CAE0` / `0xCF4E Calc3D2D` upstream of `0xD3A0` object `0x570002`; `0xD3A5 -> sub_40C980 -> 0xC993` reaches `DrawObjectAlpha_Internal` for the centre. Other halo calls `0xD5F5..0xD796 -> sub_40C9A0 -> 0xCABE` are independent. This is historical REA evidence read from GitHub, not a new binary disassembly or confirmation of the eventual GPU primitive type.
2. **Central direct semantic lifetime.** `VRLensFlareProjected2D::LensCentreEnter/Leave` wraps the exact D3A5/D3AA interval with a per-thread call epoch, saved scope and producer; queue-active/nested/disabled-VR calls cannot claim the exact centre. The `C993` wrapper admits `WorldBillboard/LensFlareCentre` only when that parent owns it and `objectId==0x570002`, then scopes `ScopedExactProducerSemantic` and `ScopedExactLensCentreGpuDraw` around the original synchronous `DrawObjectAlpha_Internal`. If `VRLensFlareCentreEnabled=false`, only this original centre object is skipped; CABE/sky/desktop are not. No SpriteNode is created by this direct wrapper, and an unrelated queued D3DX HUD node cannot borrow its epoch.
3. **CABE is a different source, not a second proven sun.** The `0xCABE` hook calls the same original object renderer with `ProjectedScreenEffect2D`; this is an exact *source tag*, not an assertion that any one 3D projected ring maps to one observed bright spot. R30's projected/SceneEffect classification requires owned original game WVP and a perspective projection; spatial billboard and flat HUD classifications depend on the matrix, otherwise the route fails closed. This cannot be replaced with a generic alpha/SkyGlow or 'all flare objects are centre' rule.
4. **Physical GPU boundary (conditional).** The game's original `DrawObjectAlpha_Internal` must issue an actual D3D9 primitive before `CapturePhysicalDrawCommand` can bind effective scope, producer, queue node/epoch and C993 call epoch. `R30GetExactLensCentreRawWvp` additionally requires no queue, `WorldBillboard`, original `c64` same-call provenance, shader+epoch, latched pose and a bounded draw serial. In the reviewed R30 world-classifier, `SelectWorldRoute(exactCentre, rawOwned)` returns either exact world stereo or preserve-original; the historical verified-road/rebind WVP is explicitly disallowed for the centre. Thus `C993 tagged` does **not** entail `C993 two eyes drawn`.
5. **Per-eye replay and fail-closed restore.** The R33 dispatcher samples physical source at the outer Draw; if raster resynchronization or exact raw c64 proof fails, it executes one original game Draw instead of treating C993 as ordinary world or XYZRHW HUD. If eligible, its specific centre path checks the native pre-left source/pair and right-eye source coherence (`SameCentreForRightEye`); the left Draw alone is insufficient to declare a right-eye image. The distinct CABE/SceneEffect candidate may instead take R30's source-owned projected route or preserve its original draw. A physical hook's owner/install chain and actual D3D9 HRESULT/FVF/VS/RT/viewport/depth/StateBlock restoration remain unobserved here.
6. **Optional effect is a third layer.** `R30BeforeScreenDrawForSkyGlow` captures scene-before-HUD only for a qualifying screen boundary; `R30ApplyStereoSkyGlow` composites independent left/right reduced/blurred targets at Present when enabled. A bright centre surviving omission of the C993 source can instead be an outer CABE object, SkyGlow contribution, game scene/sky, or an eye-composition error. The source does not establish which. No claim of a new resource-generation bug is made: prior 01350 already covers that condition.
7. **Frame admission is stricter than any sun tag.** `stereo_renderer_r7.inc::PresentDest` requires world stereo, actual duplicated draw, valid pose/metadata/resources and no right-eye/restore failure; post-Present DirectGPU EVENT publication (or SBS fallback/hold) is a separate gate. The x64 R23 host may submit a fresh, cached or no layer to `xrEndFrame`. Neither a C993 hook log nor a R33 route summary proves a current exact-SHA sun pixel in Quest3/VDXR.
