The 0x4C50A0 conditional partial drain and 0x449050 full drain can be distinct queue traversals.
2. **Source texture/semantic → queue identity**: `put_sprite_ex2_dest` transactionally replaces sprite UV and independently restores its child mask UV after the original native producer, before `TagDirectVrSpriteNodes`; the latter admits only source-proven appended live-root nodes. `VRHudQueueSemanticBridge::QueueNode` at 0x2D762 invokes R64 BeforeQueueNode then `SelectSpriteQueueNode`, which consumes tagged scope/producer and increments selection epoch; 0x2DCB4 ends the walk. Type1 mask **branch flag and mask/composite pass identity are not fields of `PhysicalDrawCommand`**; that struct captures semantic scope, producer, queue node/epoch, queued bit and optional lens epoch. This does not prove the original mask state was lost.
3. **Native GPU → both eyes**: if original type1 mask emits UP draws (supported by historical REA but not demonstrated on this build at Quest3), R26+HUD `DrawPrimitiveUPDestR30` / `DrawIndexedPrimitiveUPDestR30` consumes semantic then tries XYZRHW preparation/dual-eye execution; noneligible draws return E_NOTIMPL and follow `R30GuardScreenSpace` original/R29 fallback. `R30ExecuteXyzrhwStereo` performs left UP call; switches right RT/depth/viewport; calls right UP; restores and records failure/incomplete state. 4. **Present/OpenXR**: R9 `PresentDestR9` requires world-stereo, duplicated draw, pose metadata and no incomplete/right failure before active stereo, otherwise uses conservative mono/direct transport fallback. Classic/Direct host then selects a frame/layer; `main_r23.cpp` calls `xrEndFrame`.
