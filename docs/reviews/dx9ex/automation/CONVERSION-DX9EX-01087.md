## 3. Finding versus hypotheses; falsification gates

**CONFIRMED (source only):** `R27`'s nominal new-Present/256-draw `R28EffectDraw` capture does not always execute live raster getters. A reliable nonempty R23 StateBlock shadow short-circuits that call. This avoids redundant CPU work when coverage is correct. It is inaccurate to label that path as a guaranteed live scissor check per Present, or to blame per-draw getter overhead there without counters.

**UNPROVEN screen/performance hypothesis H1:** an unobserved StateBlock target, third-party state modification, or implicit RT/viewport change *not correctly invalidating trust* might leave shadow scissor stale while R27's forced request returns it; wrong per-eye clipping or additional pixels could result. **Falsify** with same-frame actual `GetViewport/GetScissorRect` versus shadow at both sides of a verified physical effect draw, target ID/StateBlock Apply ownership, `R23CaptureActualGameState` branch choice, RT0 serial, L/R HRESULT+RT/scissor and recorded binocular image. Existing explicit SetRenderTarget live resampling and StateBlock invalidation may already fully prevent the scenario; no stale case observed.

**UNPROVEN frame-cost hypothesis H2:** dense-stage slowdown may be from native transparent alpha fill, draw submission, shadow/occlusion, DirectGPU copies or host cached/wait frames rather than CPU raster getters. **Falsify** by comparing same-SHA/same-scene GPU valid intervals, authenticated shader/producer fingerprints, R28 source p95/p99 and thread CPU, DirectGPU ring backpressure/fence timeout, host actual submitted frame IDs and cached projection ratios. If CPU getters are not executed under reliable shadow, a hypothetical reduction of those calls **cannot** explain a GPU-side or XR-side delay. `nonCpuMs` and GPU timestamp intervals alone are not occupancy or an identified windshield.

**Evidence not available:** original per-material GPU producer XREF/disassembly, unmodified frame-by-frame texture and shader IDs, live scissor/cull/alpha snapshots, binary/host exact SHA, HMD eye poses/non-zero cant, on-device FPS/p95/p99. No numerical gain or actual visual defect is reported.
