## EVIDENCE — pinned GitHub source, no device run

1. **Fresh default ownership.** `AGENTS.md:1-5` and `CMakeLists.txt:96-108,135-161` make fresh default R26+HUD, not R84; `stereo_renderer_r30_r26_safe.cpp` is the active R30 HUD/SkyGlow review owner. Exact user ZIP cache/compile options were not inspected and are NOT inferred from CMake defaults.
2. **Epoch denotes successful copy, without a resource-generation identity.** `src/vr/d3d9/stereo_renderer_r30_r26_safe.cpp::R30CaptureSkyGlowSceneBeforeHud:1157-1191` skips repeat when `R30SkyGlowSceneCaptureEpoch == PresentEpoch`; otherwise ensures resources, copies both `BackBuffer` and `RightEyeSurface` to separate `reduced[0/1]` via `StretchRect`, then stamps that epoch **only if both copies succeed**. `::R30BeforeScreenDrawForSkyGlow:1194-1212` stamps `ScreenDrawEpoch` before attempting the first eligible HUD boundary; failures deliberately cannot capture already-HUD-filled surfaces later.
3. **Ensure can reallocate the captured storage.** `::R30EnsureSkyGlowResources:974-1016,1070-1081` rechecks each reduced/temp texture, three shaders, backbuffer size, derived glow width/height and the **current** `Settings::SkyGlowFactor.get()` at each invocation. On mismatch it calls `R30ReleaseSkyGlowResources` and re-creates the textures/shaders; `::R30ReleaseSkyGlowResources:924-939` zeros dimensions/factor but does not invalidate either capture epoch. Therefore an epoch previously stamped on the *old* textures is not itself proof that *new* textures contain the pre-HUD L/R capture.
4. **Present can trust that stale epoch.** `::R30ApplyStereoSkyGlow:1214-1259` rejects ineligible world/eye/GOAL/TIMEUP/warp modes, and skips if there was a HUD draw but no clean snapshot. If the snapshot epoch still equals `PresentEpoch`, that guard passes. It then invokes **another** `R30EnsureSkyGlowResources` at :1258, with the current settings. In the eye loop, `::R30ApplyStereoSkyGlow:1287-1323` executes the fallback `StretchRect` **only when** capture epoch differs from `PresentEpoch`; an in-frame recreation with unchanged epoch would therefore omit a fresh input copy and pass the newly allocated `reduced[eye]` to the bright pass. This is the independently auditable conditional ownership gap.
5. **Exact condition and contrast.** With stable factor, backbuffer description and valid textures between pre-HUD capture and Present, Ensure returns existing resources and the old snapshot remains valid: this review does NOT claim a routine double-halo. The alternative no-pre-HUD case uses Present-time `StretchRect` (subject to separate HUD contamination guards), and Reset explicitly releases SkyGlow resources **and invalidates both epochs** via `::ResetDestR30:1511-1520`. The conditional seam is **resource recreation within one PresentEpoch without Reset epoch invalidation**, e.g. a positive SkyGlowFactor or dimension change between the two Ensure calls; its real-world reachability has not been demonstrated.
6. **Submission and state cannot prove the image.** `::R30ApplyStereoSkyGlow:1343-1429` does per-eye blur/composite and StateBlock/RT/depth/viewport restore; `::PresentDestR30:1492-1509` delegates underlying Present. `src/vr/d3d9/stereo_renderer_r7.inc::PresentDest:1625-1707,1710-1744` requires separate eligible stereo and optional DirectGPU post-Present completion before publication. `vrhost/src/main_r23.cpp:3330-3413,3559-3616` distinguishes a fresh L/R projection, a previously released cached pair and actual `xrEndFrame`. Success of any earlier call does not establish that new bloom textures had valid pixels or that Quest3 displayed an affected frame.
7. **Original queue / nonconflation.** `docs/automation/OUTRUN_REA_RENDERING_ARCHITECTURE_20261018.md:62-80` maps +TIME numeric source and deferred sprite ownership separately from lens centre/rings/SkyGlow. `src/vr/game/render_semantics.hpp::PhysicalDrawCommand:1298-1312` retains producer and queue-epoch identity at physical Draw; a semantic HUD label or first pre-HUD trigger is not proof of a particular sprite or HMD pixel. No fresh original disassembly, GPU trace, VDXR recording or device-loss/setting-change experiment was performed.
8. **Prior finding isolation.** 01326 identified SkyGlow optional per-eye *failure result propagation*, 01348 identified potential R22/R31 *StateBlock resync*, and 01349 separated *R84-only particle DynamicVB* from the default owner. This task inspects a different snapshot-content/resource-generation predicate; it neither reuses those findings as new nor claims a measured defect.
