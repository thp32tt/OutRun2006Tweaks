3. A tracked translated `D3DPOOL_MANAGED` 2D GPU texture may own a SYSTEMMEM CPU shadow. `R14MarkExternalGpuWrite` invalidates `validMask` and sets `retirePending`, then detaches an unlocked shadow. With an outstanding CPU shadow Lock it instead records `externalWriteDuringLock`; final `TextureUnlockRectR14` refuses the conflicting CPU upload (`D3DERR_INVALIDCALL`) and retires after the final unlock. DirectOnly and unregistered 2D textures do not have the same shadow-retirement work.
4. `UpdateSurfaceDestR14` first calls native UpdateSurface; only **on success**, a non-null destination, zero thread-local internal-upload depth, successful destination `GetContainer(IID_IDirect3DTexture9)` and non-null texture does it call `R14MarkExternalGpuWrite`, then Release the temporary AddRef. `StretchRectDestR14`/`ColorFillDestR14` share this destination-surface-container path through `R14MarkSurfaceExternalWrite`. A successful native surface operation whose destination has no 2D texture parent is a normal negative control; it cannot be assumed to affect a registered R14 texture.
5. `UpdateTextureDestR14` checks native success/nonnull destination/depth==0 too, but obtains the 2D identity via `IDirect3DBaseTexture9::QueryInterface(IID_IDirect3DTexture9)`, not a surface `GetContainer`. Cube/volume/non-2D destination or a failed QueryInterface does not trigger R14 2D shadow retirement. The **native API result is returned unchanged** in each hook even if identity lookup does not succeed. A registered 2D texture whose identity query unexpectedly failed would therefore remain unchanged in the R14 shadow registry; reachability of that abnormal case is NOT established.
6. The installed device UpdateSurface hook may observe this nested call, but depth>0 prevents treating the internal upload as a competing external GPU write. If that upload fails, `R14CopyWholeLevelByLock` tries an exact-mip direct-lock copy; failure propagates into `TextureUnlockRectR14` validMask/retirePending/retirement. These internal outcomes are not evidence of a successful external write.
