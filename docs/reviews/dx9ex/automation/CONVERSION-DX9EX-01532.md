2. The same function builds `P=TransformCoord(S, cam.view(+0x140))` (:598-604), derives screen visibility `sx,sy` from that camera (:604-620) and only enters the main visible branch when `P.z<0`. It then calculates `axis=(-P.x/P.z,-P.y/P.z,-1)` and loads camera screen matrix `+0x1c0` (:646-655). **For a consistent camera that co-translates its eye and view**, a pure translation cancels in this camera-relative direction: the angular sun centre need not gain finite parallax even when stereo eyes are distinct. A head **yaw** changing the camera view *must* rotate the directional ray relative to the eye unless the sun itself rotates along with the view. This is a mathematically conditional negative control, not an observed headset outcome.
