- A cockpit windshield alpha draw might use indexed shader/VB on the main target rather than UP/D3DX and be expensive twice (GPU overdraw), or an intermediate offscreen water/reflection texture might be produced once then sampled into both eyes; neither has a matching original producer+physical call.

- Alternative causes for a frame drop: opaque world pixel cost, windshield blending/overdraw, stencil/depth state, MSAA, resource transition, DirectGPU StretchRect/fence, host copy/wait/reprojection, and shader profile. These are independent competing explanations.
