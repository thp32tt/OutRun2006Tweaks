1. **Original production and physical draw.** Archived REA for original OR2006C2C.exe SHA256 `68ceb386829066f8455b9d027320af962584321f3e2e8a79c72841495a6134c3` maps +TIME original call sites and SpriteNode scheduler `0x449050 -> 0x42D710`; its four branches are D3DX `0x42A0A0` (delayed Flush/End possible), direct-UP `0x42C0F0`, animation quad `0x42A3A0`, and mask/composite `0x42A800`. R26 exact producer/semantic/queue/epoch guards and physical GPU submission must be traced independently: a queue tag or D3DX Draw alone does not prove a binocular draw.
2. **Installed R7 game state hook.** `SetDepthStencilSurfaceDest` forwards game `SetDepthStencilSurface`, checks success, records `changed=(TrackedDepthStencil!=surface)`, replaces tracked COM reference, and only on changed+stereo-resources-ready+main-backbuffer evaluates compatible right depth. If the new `surface` is non-null, compatibility compares dimensions, depth format, MSAA type and quality against `RightEyeDepth`/backbuffer; it does **not** compare the left surface's identity with the previously synchronized *main* left-depth surface or a depth-content generation.
3. **Same-descriptor branch.** For `compatible=true`, `SetDepthStencilSurfaceDest` logs reuse and makes no assignment to `RightDepthSynchronized`, `RightStencilSynchronized`, `FrameStereoIncomplete`, or `FrameFailureReason`; its `else` incompatible branch instead considers `StereoFailureDepthStateChanged` and calls `CreateRightDepthForTracked`, which initializes sync false for a non-null left depth. This is a confirmed state-transition asymmetry, not proof that the original game ever binds a second distinct same-format main depth.
4. **Concrete conditional sequence.** At main-backbuffer scene start, left allocation A and right allocation R have established depth/stencil state after a full duplicated clear and/or matching prior left/right rendering; `RightDepthSynchronized=true` (and stencil true when applicable). The game successfully binds a genuinely different main depth B while remaining on the backbuffer, with B having the same descriptor as R but different pre-existing depth/stencil contents. No subsequent matching full-depth/stencil clear or separate explicit conservative invalidation takes place. The hook sees `changed=true` and `compatible=true`, keeps R and its old sync flags. Descriptor equality is not pixel/depth content equivalence.
5. **Admission and actual L/R.** `PrepareDuplicatedDraw` checks right-depth/stencil sync only when flags are false; with retained true flags, it does not run `TryBootstrapRightDepthFromRecentClear` and does not fail closed on the `DepthTestActive`/`StencilTestActive` unsynchronized guards. If a bona fide world draw or R62 finite HUD fixed-function physical draw meets all independent semantic/FVF/VS/pose/viewport/resource conditions, `ExecuteStereoDraw` can issue successful LEFT on B and RIGHT on R, restore RT/depth/viewport/projection with checked HRESULTs, set world/duplicated frame flags and return LEFT HRESULT. The actual physical draw category remains source-dependent (D3DX Flush/End vs direct-UP/quad/mask; R62 exact FVF142 only).
6. **Final frame path.** R7 `PresentDest` checks world/duplicated flags, pose and resource validity, poisoned/right-fail guards, then prefers DirectGPU or (where permitted) `ComposeSbs`, calls original Present and publishes stereo frame/pose metadata on success. No color/depth-content equivalence test between B and R is in this path. An accepted frame could therefore have an image-level depth occlusion mismatch **only if** the game's B binding, contents and tested D3D draw sequence occur. OpenXR host `xrEndFrame`, Quest3 output and user-visible depth/popping symptoms are UNTESTED.
7. **Essential contrasts.** Restoring the SAME original left main depth A after an auxiliary pass can be safe: the immediately prior tracked depth pointer differs, but right R still represents A; broad invalidation on *every* `changed` would cost performance or force mono. In contrast, genuinely new B with equal descriptor is not proven safe. Null depth releases right depth; incompatible descriptors trigger recreation; full duplicated clear after switching to B can reestablish both; depth/stencil-disabled draws may have no visual effect; other R7 failures/poison can independently suppress stereo. These are separate outcomes.
