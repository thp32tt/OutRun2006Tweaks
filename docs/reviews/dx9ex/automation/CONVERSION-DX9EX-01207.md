3. **Run epoch reset covers presentation cursor, not the shared-object cache at this site.** `vrhost/src/runtime/direct_run_epoch.hpp:1-35` defines run identity `(runGeneration, gamePid)`; `vrhost/src/main_r23.cpp:2955-2990` observes it in direct-only history and, on change, resets `lastProcessedStereoFrame`, match/cached-projection state and verified bundle. That block does **not** call `R23InvalidateDirect`, clear `directLeft_/Right_[slot]`, or reopen `OpenSharedResource`. This is a **local control-flow fact**, not proof other lifecycle boundaries cannot clear resources.
4. **Reopen key is narrower than the consumer's run identity.** `vrhost/src/main.cpp::PrepareDirectStereoSource:1345-1381` checks nonzero slot/handles/size/generation, then computes `same` using cached left/right texture and SRV pointers, numeric left/right handles and `directGeneration_[slot]`. This expression does **not** compare `frame.clientPid` or `RenderFrameRunGenerationIndex`. When `same` is true, the `OpenSharedResource` re-open branch is skipped. Within a single unchanged producer run this is a deliberate optimization, not inherently unsafe.
5. **Later descriptor/hold identity gates do not re-open an already-'same' source.** `vrhost/src/main_r23.cpp::R23ValidateDirectResourceSize:1323-1396` caches a descriptor keyed by left/right COM pointers, handles, generation, runGeneration, gamePid, extent and format, and otherwise calls `GetDesc`; it checks dimensions/format/array/mip/sample parity **on the already-opened objects**. `::R23StageDirectHold:552-644` creates/reuses host-owned hold textures; `vrhost/src/runtime/direct_hold_frame_reuse.hpp:9-42` requires frameId, slot, generation, runGeneration, PID, numeric handles **and pointers** before skipping an eye-pair copy. That prevents stale *hold-copy reuse* but does not itself verify that cached **source pointers** represent the new producer's current shared handles.
6. **Actual eyes and ACK are later boundaries.** `vrhost/src/main_r23.cpp:3200-3358` re-reads candidate Frame.v2, matches pose and stage/copies DirectGPU; it publishes a verified bundle only after `R23RenderProjection:1440-1513` draws both D3D11 per-eye targets and releases the projection swapchain image. The R32 async GPU EVENT/producer-slot ACK is distinct from queued `CopyResource`, and main gameplay `vrhost/src/main_r23.cpp:3562-3650` checks actual final `xrEndFrame` submission identity. Correct transport metadata and `Draw(3,0)` calls do not alone prove headset optical content.
