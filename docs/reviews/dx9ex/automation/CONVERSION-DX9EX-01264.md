## Producer → semantic → queue → D3DX/native → R30/R62 → L/R → restore → Present/OpenXR (conditional static simulation)

Previously checked-in REA `docs/research/REA_ORIGINAL_SPRITE_GPU_FOUR_PATHS_20261018.md` identifies original EXE SHA256 68ceb386829066f8455b9d027320af962584321f3e2e8a79c72841495a6134c3. +TIME six x86 E8 RVAs 0x9898E/989AD/98A10/98A36/98A89/98AC6; normal consumer 0x449050→0x42D710 reaches type0 D3DX 0x42A0A0, type0 direct-UP 0x42C0F0, type1 quad 0x42A3A0 and type1 mask/composite 0x42A800. 36 indirect calls remain unresolved. This *does not* prove a particular +TIME, menu or particle texture accesses R14 Shadow.
2. `CreateManagedTextureCompat` translates legacy MANAGED textures to DEFAULT|DYNAMIC first; if that fails and it is a 2D texture, it retries DEFAULT with original Usage. `CreateTextureCompatDestR14` reads the translated level-zero `Usage`: a DYNAMIC result goes to `R14TrackDirectLockable`/DirectOnly, **not CPU Shadow**. The Shadow path is reached through the non-DYNAMIC translated texture, a SYSTEMMEM CPU peer, successful registration and budget admission. Failed CPU shadow creation may instead track DirectOnly; other tracking failures fail closed. Cube/volume have no non-DYNAMIC shadow fallback.
3. In tracked Shadow, `TextureLockRectR14` locks the CPU peer and stores RECT pointer presence, level lock/read-only/dirty masks. Writable successful CPU Unlock goes into `R15UploadLevel` when R15 overlay is active; it attempts exact mip `UpdateSurface` first. A failed UpdateSurface can invoke `R14CopyWholeLevelByLock` **only** for a null RECT. R14-only path has a broader fallback and is a separate negative control, not automatically the R15 active path.
4. **Confirmed static attempt-order mismatch:** `R14CopyWholeLevelByLock` reads CPU `GetLevelDesc`, locks SYSTEMMEM source `D3DLOCK_READONLY`, then selects destination flags `D3DLOCK_DISCARD` solely if `entry.gpu->GetLevelCount() <= 1`; it does NOT inspect the destination `D3DUSAGE_DYNAMIC` bit. But an R14 Shadow destination was selected from a non-DYNAMIC translated level-zero GPU texture. If the single-level destination rejects DISCARD, the function retries GPU LockRect once with flags 0. A multi-level destination starts with flags 0. This proves a **potential redundant GPU lock attempt in a narrow fallback path**, not observed native rejection or missing pixels.
5. Upon successful destination LockRect, compressed formats DXT1–5 use `max(1,ceil(cpuDesc.Height/4))` block rows and other formats use `cpuDesc.Height`. Row length is `min(abs(source.Pitch), abs(destination.Pitch))`; signed Pitch determines row steps. There is no direct validation of required format block-row payload against the minimum pitch, nor a destination-level `GetLevelDesc` comparison inside this copy function. On legitimate locks, native Pitch should represent legal row storage; padding bytes copied or unequal pitches alone do not prove corruption. A hypothetical too-short accepted Pitch might allow partial logical row copying while returns still indicate success; no such driver input is observed.
6. If GPU Lock fails even after zero-flag retry, `R14CopyWholeLevelByLock` still Unlocks the SYSTEMMEM source and returns failure. When destination Lock succeeds, both Unlock HRESULTs are checked. On failed R15 upload, validMask clears and retirePending prevents reuse until outstanding CPU locks drain. No failed native lock becomes a falsely successful tracked Shadow upload.
7. Physical visibility is conditional: the exact texture/mip must be sampled by an actual original GPU DP/DIP/UP from one of the four producer families. `PhysicalDrawCommand` snapshots immutable producer/scope/queueNode/queueEpoch. D3DX Begin/Draw is CPU staging; `FlushDest/EndDest` only restores homogeneous exact owner at GPU submission (otherwise fails closed). R30 DIP dispatches F11 ImGui→R62 fixed-function candidate→XYZRHW→guarded R29/native, with `R62 E_NOTIMPL` only an intermediate rejection. R7 hooks Draw*/RT/depth/Present. L/R primitive HRESULT, StateBlock/RT0..N/depth/viewport/WVP restore and valid pose/eye extents gate R9 stereo; Present may preserve original mono fallback. The x64 host must join matching actual frameId/source and a submitted `xrEndFrame` layer. No such end-to-end runtime join, adapter-dependent Lock result or measurable frame cost was collected.
