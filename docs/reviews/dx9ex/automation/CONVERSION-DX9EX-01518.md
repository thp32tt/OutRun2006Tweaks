5. SOURCE IMAGE PRESERVATION BEFORE COMPOSITION: `stereo_renderer_r7.inc:1500-1507` copies original full-width BackBuffer to `LeftResolveSurface`, RIGHT source to `RightResolveSurface` and snapshots D3D9 StateBlock, RT0, depth and viewport. This copy is not an automatic backbuffer-color rollback.
6. CONDITIONAL FAILURE PATH A (precise): `stereo_renderer_r7.inc:1509` switches RT0 to BackBuffer, clears the full target to BLACK, draws LEFT half successfully from `LeftResolveTexture`; the subsequent RIGHT `DrawTextureHalf` returns false because `SetTexture` or `DrawPrimitiveUP` fails. `rightOk=false`, `success=false` even with successful EndScene. Original right half remains black **if** no other write occurs between Clear and Present; left half may contain the prior source scaled into half width.
7. CONDITIONAL FAILURE PATH B: viewport+Clear succeed but LEFT half texture/draw fails, leaving black full buffer; or both half draws succeed but EndScene fails, leaving potentially completed SBS pixels while the function returns false. Exact physical pixel persistence following a failed draw/EndScene is driver-dependent; scenario A assumes the successful Clear and left Draw take effect.
8. RESTORE IS NOT COLOR ROLLBACK: `stereo_renderer_r7.inc:1510-1516` checks StateBlock Apply, RT0/depth/viewport restores and calls `NoteRestoreFailure` only for failed *state* restore. There is no `LeftResolveSurface -> BackBuffer` recovery on failed `rightOk`/`success`. `StateBlock::Apply` reestablishes pipeline bindings, not prior render-target color pixels.
9. PRESENT: `stereo_renderer_r7.inc:1674-1702` increments `StereoComposeFailure` and poisons incomplete frame, publishes in-flight `StereoSbsFallbackMono`, but **still calls the original `Present`** without restoring pristine mono BackBuffer first. If Present succeeds, `:1718-1734` publishes fallback/mono state and clears stereo metadata. Fail-closed *metadata* alone is not a proven rollback of submitted pixels.
10. HOST / OPENXR: An SBS/Desktop-Duplication consumer could sample a just-presented partial/black fallback source if it uses this backbuffer under the appropriate timing/mode; alternatively the x64 host can retain an earlier safe image or reject it. No host acquire, xrEndFrame, Quest3/VDXR view, game GPU result or FPS measurement was performed. This review does **not** claim actual headset half-black frames.
11. PERFORMANCE: Failure-only recovery must not change normal fast DirectGPU or successful SBS composition. Any speculative extra copy/wait on every Present could harm VD High 120Hz budget; no cost is measured.
