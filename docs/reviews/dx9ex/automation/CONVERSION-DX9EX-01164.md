3. **Cache storage lifetime is protected, but lock acquisition can still stall a miss.** In `FileDataCache::cacheFile:645-733`, `std::lock_guard populationLock(cachePopulationMutex)` remains active across the cache check, opening the DDS file, pre-read eviction, allocation, synchronous disk read and insertion. `mtx1` separately guards LRU/budget, and `getFileData:735-820` returns shared ownership of a cached buffer to the D3DX-call-scoped `transientOwner`; eviction therefore does not itself prove use-after-free. The explicit VR cap is 64 MiB in `TextureReplacement::apply:1748-1758`. An overbudget file can instead be read transiently; a live cache hit does not wait on `mtx2` or `cachePopulationMutex`.
4. **Synchronous game-thread cache-miss path.** `getFileData:748-787` checks `mtx1` cache, then, on a miss, locks `mtx2`, rechecks, invokes `cacheFile(filename)`, and reacquires the cache entry. If the detached preloader is currently inside **another file's** `cacheFile`, the game-thread miss waits for the same `cachePopulationMutex` while that preloader performs its disk read. The source proves this *possible lock dependency* for concurrent calls, not its runtime frequency, duration or presence in an exact headset run. Game-thread on-demand DDS misses could also be caused by a different folder, omitted nested preload or bounded LRU eviction; no specific file or stage has been observed.
5. **DDS decode and COM resource boundary.** `HandleTexture:1211-1397` hashes the original input, chooses an optional scene replacement path, and obtains the bytes via `FileData.getFileData` (`1291-1296`) with a scoped shared owner. `SceneDdsOriginalState` and scene 2D/cube `D3DXCreate*FromFileInMemoryEx_*_dest:1507-1640` use fast-path/native decoding with untouched-original fallback where a replacement is rejected. D3DPOOL_MANAGED and the returned `IDirect3DTexture9`/cube pointer belong to the original D3D9 texture resource path; the cache's DDS *byte* owner is not by itself a GPU texture COM owner, a SetTexture bind or a Reset survivor.
