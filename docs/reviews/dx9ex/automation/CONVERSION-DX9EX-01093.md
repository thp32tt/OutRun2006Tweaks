**Semantic and native intercept.** `src/vr/game/render_semantics.hpp::ConsumeForDraw():998-1035` consumes exact current queued provenance before a generic one-shot token; external F11 does not consume game semantics. `src/vr/d3d9/stereo_renderer_r30_r26_safe.cpp::DrawIndexedPrimitiveUPDestR30():5468-5500` asks `ConsumeForDraw` for eligible physical game calls, then offers `R30TryXyzrhwIndexedPrimitiveUP`; a returned `E_NOTIMPL` delegates to `R30GuardScreenSpace` with native/R29 fallback. An enum, opacity or shader family is **not** positive last-GPU identity. Unlike type-0 deferred D3DX, DIPUP source attribution requires a physical-indexed call, its current semantic node and queue epoch.

**Confirmed indexed-window admission and index remap.** `R30TryXyzrhwIndexedPrimitiveUP():3967-4102` validates `D3DFMT_INDEX16/32`, index/vertex pointers, index count (maximum 524288), vertex stride, and `DeclaredWindow(minVertexIndex,numVertices,...)`. `src/vr/d3d9/r30_indexed_up_bounds.hpp:5-31` caps the *declared end* at 262144 and rejects any referenced index outside `[minVertexIndex, declaredEnd)`. The function computes `windowVertexData = vertexData + minVertexIndex * stride`, builds `scratch.used` over `numVertices` and marks only referenced vertices. For a nonzero min, the indices are rebased into a single scratch index buffer shared by both eyes; both calls use `drawMinVertex=0`. Limits and rebasing are **protective code**, not an identified crash.

**NEW confirmed CPU-copy distinction, versus sparse traversal.** The same indexed function sets `vertexCount = numVertices` at `:3994-4005`; `R30TransformXyzrhwStereo():3770-3802` invokes `R30TransformXyzrhwVertices` once per eye and, on mismatched full-reprojection acceptance, can invoke both a second time with affine-only mode. `R30TransformXyzrhwVertices():3403-3448` first sizes each scratch to `vertexCount * stride` (rejecting >4 MiB per buffer) and copies the **whole declared vertex window** with `std::memcpy(out.data(), source, bytes)` even when `usedMask` contains few selected entries. The mask is used at `:3445-3470,3670-3674` to avoid modifying *unreferenced* vertices during transform; it does **not** avoid the full-window memory copy nor full declared-window scratch footprint. The optional bilateral affine retry can re-copy both original full windows (`:3667` and `:3779-3802`). Thus sparse referenced vertices reduce per-vertex reprojection work but do not proportionally reduce pre-eye memory movement. This is a precisely bounded source fact, not proof that an actual game draw supplies sparse windows.

**Illustrative static thought experiment (NOT observed runtime).** For a hypothetical valid triangle indexed draw, `minVertexIndex=100`, `numVertices=10000`, only three referenced indices and `stride=32`, the admitted stereo path copies 320000 bytes *per eye* (640000 for initial pair) despite three transform-selected vertices, plus optional retry copies. Actual GPU driver uploads, render time or game usage **cannot** be inferred from this synthetic input. A dense contiguous index window can make this cost entirely appropriate; compacting solely to three vertices may alter original index/vertex semantics or increase remap overhead.

**Physical stereo, restore and Present.** For an admitted indexed native route, `R30TryXyzrhwIndexedPrimitiveUP():4070-4102` calls original DIPUP separately on L/R scratch with identical rebased index buffer. `R30ExecuteXyzrhwStereo():3805-3920` performs left draw, right RT/depth/viewport setup, right physical call and `RestoreRightPassState`. Failed right call or restoration poisons the frame and arms fail-closed mono fallback; a successful duplicated draw is **not** sufficient world-stereo publication unless world evidence is authoritative. Indexed rejected/non-XYZRHW draws can use conservative R29/native paths and cannot be credited to this stereo-copy analysis.

`src/vr/d3d9/stereo_renderer.cpp::PresentDestR9():676-825` requires completed world/duplicate draw, pose and no right-eye/incomplete failures before attempting DirectGPU or SBS. It restores mono if no complete composed stereo, publishes successful stereo only after actual D3D9 Present, and explicitly suppresses classic fallback in DirectGPU-only mode. On the host, `vrhost/src/main_r23.cpp:3134-3220` rejects mismatched/partial SBS source and enforces frame-history QPC/pose matching, independently of indexed CPU copy; `:3559-3635` verifies `xrEndFrame` interception's actual submitted frame/layer before pacing attribution.
