The independently reconstructed original `sun_flare_40cbc0` computes the sun anchor `S = Eblend + D`, with `Eblend = t*cam[0xD4..0xDC] + (1-t)*cam[0x3A8..0x3B0]`, `t=camera_blend_4493e0` and `D=light[0x899CCC..0x899CD4]` (original :566-580). **Neither Eblend source is the same address as `cam[0xF8..0x100]`.** `P=View(+0x140)*S` derives the central screen axis (:584-601,646-649).
2. In that same producer, `eye=cam[0xF8..0x100]`, `target=cam[0x104..0x10C]`, `view_dir=target-eye`, and `sun_dir=S-eye` are used to compute the `facing` dot product (:608-630). `facing` changes ring/spread logic for outer flare children (:695-715). Thus even if central projected P does not move, the **brightness/shape of distinct flare material contributions** can change with a different source-eye definition. This is not proof of duplicate draws.
3. The current mod `ApplyCullingCameraSync` requires `VRCullingCameraSync`, valid latched head inverse, `VRMatrixOrder==0`, readable globals, game camera and renderer view (:1326-1344). It builds `cameraWorld=inverse(baseView*HeadInverse)`, then restores/saves and directly writes **only** `EvWorkCamera::cam_pos_F8` and `::look_pos_104` (:1362-1372). It **does not directly write** the original emitter blend fields `+0xD4` or `+0x3A8` in that function. This is a verified write-set distinction, **not evidence those fields never change via the game or any other code**. Correlating `EvWorkCamera` layout with original retail x86 addresses and the actual in-frame pointer remains necessary.
4. Consequence: the simple 01532 “pure translation cancels” negative control holds only when `Eblend` and the origin represented by `View(+0x140)` co-translate. If HMD motion changes F8/104 but not Eblend, the `sun_dir=S-F8` vector/facing may vary while `S` stays anchored to the old blended game eye. Conversely, if original game logic recomputes the blend fields/view matrix coherently before this producer executes, the hypothesis is weakened. Nothing here establishes which branch occurred on Quest3 or that the image is head-locked.
