Irrespective of right-stage success it calls `RestoreRightPassState(..., originalConstants=nullptr, restoreWvp=false)`; R62 then separately restores original PROJECTION (`:5296-5307`).
5. **Exact restore contract (verified static):** `src/vr/d3d9/stereo_renderer_r7.inc::RestoreRightPassState:1462` checks RT0 restoration **only when savedRt is non-null**, always attempts depth-stencil restoration (including saved null), always attempts `SetViewport(savedViewport)` and restores c64 WVP only if `restoreWvp=true`. It does **not** snapshot/rebind RT1+ or a D3DX StateBlock, but R30SafeStereoBase had already rejected tracked active auxiliary MRT and its own right pass changes only RT0, depth, viewport and, for R62, PROJECTION separately. Consequently RT1+ omission is not independently proven to be a bug. The conditional savedRt check is a failure-detection blind spot only if a genuinely eligible draw can have null/stale TrackedRenderTarget; the current backbuffer/resource admission suggests otherwise, without proving every device-loss/reentrant case.
6. **Failure gates and restoration:** In `R30ExecuteXyzrhwStereo:3931-3944`, failed right state or draw flags `FrameRightDrawFailed`, invalidates right depth if appropriate, poisons and arms fallback; unsuccessful restore additionally invokes `NoteRestoreFailure` and safe fallback, even though the helper returns the successful left HRESULT. `NoteRestoreFailure` (`stereo_renderer_r7.inc:1461`) independently sets `FrameRightDrawFailed` and `StereoFailureRestoreFailed`. A restore that returns success does not *by itself* verify RT0/depth/viewport hardware readback nor all RT1+ slots; neither does it establish actual state corruption.
7. **Comparison routes / negative controls:** R7 generic right-eye path (`stereo_renderer_r7.inc:1551-1554`) restores RT0/depth/viewport and optionally world constants/fixed-function transforms. R30 ScreenHud c64 route (`stereo_renderer_r30_r26_safe.cpp:5028-5109`) additionally restores original WVP; R62 independently restores PROJECTION; F11 external ImGui (`:3000-3070`) also restores raster state. `E_NOTIMPL` at R62 eligibility transfers to other R30 candidates/native guard, whereas a taken R62 native failure is terminal to that early owner; neither path authorizes a second same-eye DIP replay.
8. **Present/OpenXR is the final gate:** `src/vr/d3d9/stereo_renderer.cpp::PresentDest:692-822` requires world stereo, duplicate-route record, !FrameRightDrawFailed, !FrameStereoIncomplete, valid pose/resources for stereo composition; incomplete frames can restore *existing valid* mono backup but cannot promise one exists.
