- **Fact:** the actual compiled R26+HUD owner excludes the R33 TU containing the explicit `EndSpriteQueueFrame` call. Its inspected R30/R27/R7 Present/Reset and canonical queue hook do not invoke an equivalent. The semantic tag system is intentionally non-destructive at each partial queue epilogue. Unlike #01425's independent `NextDrawScope` one-shot, this concern is the **SpriteNode tag table's frame retirement** under different compiled stereo owners.
- **Hypothesis:** if an original producer tags nodes that never get selected in a Present and no other compiled frame fence expires them, stale entries may persist until re-registration, reuse or capacity replacement. That could alter exact-vs-generic routing for a recycled node and/or increase bounded lookup work, but no such frame, inflation, L/R mismatch, frame stall or headset symptom has been reproduced.
- **Falsifiers:** (a) exact R26 package/CMake-cache and linked call graph prove a reachable `EndSpriteQueueFrame` or equivalent retirement in another compiled owner; (b) matched frame telemetry proves all published tags are always consumed/replaced before each Present for relevant scenes; (c) semantically stale serials are provably rejected before physical use, even on 560-slot ring reuse; (d) controlled dense HUD/type0/type1 and partial-queue captures show no stale table growth or old attribution at exact D3D9 draw.
