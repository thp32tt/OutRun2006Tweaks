3. The decoder at `main_r23.cpp::R23DecodeRgb:735-755` reads **only** R,G,B components (BGRA permuted accordingly) and ignores byte 3 alpha. `::ConsumeProjection:912-947` populates `decoded[eye][i][c]` for c=0..2 and `pairAbsMean/pairAbsMax` using RGB channels only, when both decode-valid. Therefore the two reported diagnostics **do not measure the same channel set**; raw hash inequality need not mean a change in sampled RGB lens intensity/position.
4. Constructive **static, not GPU-executed** falsifier: take two 5x3 sampled 8-bit RGBA arrays with identical R,G,B at all 15 positions and equal alpha at positions 0..13, but use L alpha=0 and R alpha=255 at position 14. `finiteL=finiteR=15`, `pairAbsMean=pairAbsMax=0`, while `hashL != hashR`: on the last sample's final byte the distinct inputs enter an XOR then multiplication by odd FNV prime, a one-to-one transformation modulo 2^64, so the final hashes differ. This verifies **alpha-only hash divergence** without inventing a real lens pixel. The same control applies to selected BGRA formats.
5. Separate encoding limitation: the format preference lists `*_SRGB` **ahead of** UNORM, but `R23DecodeRgb:735-748` divides byte values by 255 without sRGB transfer-function linearization. When an SRGB projection format is selected, `pairAbsMean` is an **encoded RGB code-value difference**, not a quantitative linear radiance/halo energy delta. Neither hash inequality nor positive pairAbsMean proves extra native same-eye flare Draw, and zero pairAbsMean does not disprove a flare lobe outside the 15 positions (01547).
6. Alpha can matter to other blending stages depending on actual layer flags/compositing; this review does **not** assert all alpha differences are invisible in the headset. It asserts that the current grid output cannot isolate **RGB flare duplication versus alpha-only provenance** without separately logging alpha/format and real composite state. In `main_r23.cpp:3048` the projection struct is value-initialized; no claim about final runtime blend mode is made here.
7. This probe runs downstream of actual game L/R source pixels and the host projection, not at original lens emitter/native draw.
