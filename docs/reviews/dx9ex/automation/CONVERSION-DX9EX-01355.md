### Conditional original-producer -> GPU -> headset simulation (not a captured frame)

1. Original stage function **VA 0x00498670** contains direct E8 sprite CALL RVAs **0x9898E (B4)**, **0x98A36 (B5)** and **0x98AC6 (6C)** plus numeric/text CALL RVAs **0x989AD, 0x98A10, 0x98A89**. The checked-in original EXE REA report verifies all six E8 bytes/targets; the newer mod source explicitly excludes the 6C **mode=2** animation from the exact +TIME finite-HUD banner. **Six physical source CALLs does not mean six admitted ScreenHud owner hooks.**
2. For the two source-admitted B4/B5 sprite calls, `StageExtensionEnter` stores VR/queue/epoch admission, root/tail snapshots and source serial, then conditionally brackets synchronous exact producer work. `StageExtensionLeave` tags only verified newly appended nodes on stable roots, may flush a proven isolated direct D3DX batch, and restores scope. The three exact print parents use the same enter/leave functions. Atomic install/rollback covers **two sprani + three print** E8 parents; the code deliberately does not hook 0x98AC6. The 0x98A10 post-return handler uses RVA 0x98A18 rather than unsafe 0x98A15.
3. Original kind-1 animation producer chain: 0x00429530 -> 0x00428A10 -> 0x00429460 -> 0x00429350 -> 0x00428BD0 -> 0x0042D0C0 -> 0x0042DD50 -> priority queue **0x0042D710**. Only **if node[0x18] & 0x40000 != 0**, queue dispatches original **0x0042A800 masked/composite animation**; otherwise it dispatches **0x0042A3A0 animation quad**. Both were mapped to original D3D9 primitive-UP submission in checked-in REA evidence. **Which arm B4/B5/6C takes in a real frame is UNKNOWN**; the bit's presence or a source name alone cannot prove mask execution.
4. Parallel kind-0 print/clip nodes use **0x0042A0A0 ID3DXSprite::Draw** with possible deferred `Flush/End`, or the flagged **0x0042C0F0 direct-UP** arm. These paths do **not** become the type-1 mask draw just because they share stage text or a priority queue. An optional earlier consumer through **0x004C50A0** may precede normal **0x00449050 -> 0x0042D710** consumption; two sites do not establish duplicate runtime draws.
5. During actual queue traversal, `SelectSpriteQueueNode` consumes an exact node tag and advances its queue-node epoch. Untagged or stale/rebuilt nodes retain **ScreenOverlay2D** rather than receiving a guessed ScreenHud owner. A partial queue exit does **not** retire all unvisited semantic tags; the end-of-frame Present/Reset fence controls expiration. `CapturePhysicalDrawCommand` samples queue node, producer and epoch only at the *actual* draw, so a source E8/texture/animation ID does not by itself certify the physical mask branch.
6. **If** the physical method is `DrawPrimitiveUP` on the protected R26+HUD compiled renderer, `DrawPrimitiveUPDestR30` consumes draw semantic and first attempts the narrowly gated XYZRHW path. Live null VS, XYZRHW FVF, valid viewport/stereo pose/resource and semantic classification are required. If it is admitted, R30 transforms/source-copies for left/right, submits left original UP and right UP with right RT/depth/viewport, then attempts restore. If not admitted, `R30GuardScreenSpace` may use independently proven screen-space routing or delegate the original/lower path. **Mask alpha alone grants no finite-HUD ownership.** The R62 FVF 0x142 IndexedVB path audited in 01354 is a different physical API.
7. Left/right attempted draw counts are not Quest 3 pixels. `PresentDest` requires world-stereo evidence, duplicated draw evidence, valid pose and non-poisoned frame; a **HUD-only** primitive does not by itself seed `FrameHadWorldStereo`. On eligible frames transport may use verified post-Present DirectGPU publication, SBS fallback or a held safe frame. Host R23 can consume fresh/cached projection and reaches `xrEndFrame`, but no recorded 6C/B4/B5 actual physical draw -> two-eye -> source Frame.v2 -> XR layer chain was supplied here.
