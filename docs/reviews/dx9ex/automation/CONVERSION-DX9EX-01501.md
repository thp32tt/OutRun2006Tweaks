A projected rank/FVF142 candidate has a separate ownership admission; StageExtensionTime DP/DPUP/DIPUP extra entries are strictly +TIME-gated.
3. R33 resynced raster dispatch tries the fixed-function route (DIP rank/result/ScreenHud; original stage DP/DPUP/DIPUP), then XYZRHW and R29 only if it returns E_NOTIMPL. R62 demands main backbuffer, TRIANGLELIST, live GetVertexShader=null, FVF exactly 0x142, valid current pose/resources, finite original projection, and sufficient semantic/queue ownership. R62 snapshots originalProjection and builds LEFT/RIGHT projected or finite HUD plane matrices.
4. On R62 execution, drawEye(LEFT) first calls SetTransform(D3DTS_PROJECTION, eyeProjection[0]); the only path setting drawAttempted[0]=true and calling the ORIGINAL raw Draw is AFTER SUCCEEDED(projectionSetHr[0]). A failed setter returns E_FAIL immediately: drawAttempted LEFT=false; drawHr LEFT stays E_PENDING; RIGHT lambda is never entered.
5. R30ExecuteXyzrhwStereo has already captured the exact source stamps (rank/+TIME/GOAL when applicable), checked admission, then calls R29OwnerNoteStereoDrawWithoutMonoBackup() and may note a possible depth/stencil write BEFORE invoking leftDraw. It handles any FAILED(leftHr) as if "left draw was already submitted": sets FrameRightDrawFailed, reports StereoFailureLeftDrawFailed, arms mono safety, emits RecordR30EyePair(false,false,false), and returns leftHr. This path does not distinguish failed projection SetTransform from a physically invoked LEFT native Draw reporting failure.
6. R62 still attempts final SetTransform(PROJECTION, originalProjection) in its OUTER scope, even when the inner transaction exits on the LEFT setter failure. With a successful originalProjection restore, it returns E_FAIL unchanged (because hr failed), not E_NOTIMPL; if restoration also fails, NoteRestoreFailure and R30ArmSafeFallback add a separate restore poison. R62's exactResult telemetry can distinguish projectionSetHr[0]=E_FAIL, drawAttempted[0]=false, drawHr[0]=E_PENDING (only when exactResult and VRTelemetry enabled); non-result calls do not receive this fine-grained result-specific trace.
7. R30 DIP dispatcher and R33 DP/DIP/DPUP/DIPUP routing treat a non-E_NOTIMPL fixed-function return as TERMINAL. Thus no native original GPU Draw is automatically attempted by the renderer for this command after LEFT projection setter failure; physical L/R attempts remain 0/0. This is distinct from a rejected pre-draw R62 admission returning E_NOTIMPL, which permits a lower route.
8. R7 Present requires FrameRightDrawFailed=false and FrameStereoIncomplete=false as well as world stereo, duplicated draws and valid pose/resources. Here the poison blocks *new* stereo publication; the host may reuse a prior safe projection or use guarded recovery theater if available. No Quest3 pixels, real driver SetTransform failure, or fresh OpenXR frame were captured.
9. Negative controls: (a) pre-admission failure returns E_NOTIMPL and does not run the drawEye setter; (b) LEFT setter succeeds but native LEFT Draw fails -> physical LEFT attempt count 1, same generic LeftDrawFailed report, frame veto; (c) LEFT setter+raw draw succeed, but RIGHT fails -> RIGHT-specific poison with a LEFT physical attempt; (d) both eyes and all restores succeed -> normal stable pair; (e) final original projection restore failure after TWO successful eyes belongs to review 01500.
