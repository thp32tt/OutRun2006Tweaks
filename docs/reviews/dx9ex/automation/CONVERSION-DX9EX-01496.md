4. Physical LEFT: `physicalEye(0)` must successfully bind stream0 to LEFT's VB offset, then sets `physicalDrawAttempted=true` *before* raw `DrawPrimitive`. This review assumes LEFT's bind+native Draw return D3D_OK. R30's shared stereo helper records that a private two-eye transaction has no mono backup.
5. Physical RIGHT: R30 switches right RT/depth/viewport; exact +TIME/GOAL/rank source fences do not apply to generic WorldParticle. It sets failure category `StereoFailureRightDrawFailed` *before* invoking the `rightDraw` callback. That callback first invokes `bindEye(1)` (`SetStreamSource` with right offset). On bind failure it returns a failed HRESULT **without calling raw RIGHT DrawPrimitive**.
6. Restore/return: R30 records eye status LEFT=true/RIGHT=false, poisons the current frame, and restores RT/depth/viewport; if restore succeeds, `ResultAfterRestore(leftHr, true,...)` returns the successful native LEFT HRESULT. The outer ring's `finishUp` sets stream0 to null to preserve DrawPrimitiveUP's side effect. Because LEFT *was* physically attempted, `MayUseNativeUpAfterGpuAttempt` rejects reissuing the UP draw. R33 receives non-E_NOTIMPL success and does not fall through to a second alpha draw.
7. Present/OpenXR: R7 Present requires no rightDrawFailed/stereoIncomplete before DirectGPU or SBS publication. This conditional failure excludes that frame from fresh stereo, regardless of the successful returned logical DPUP HRESULT. The x64 host may reuse a prior safe OpenXR projection or invoke its guarded mono/theater fallback; neither a host-layer choice nor Quest3 screen result was executed here.
