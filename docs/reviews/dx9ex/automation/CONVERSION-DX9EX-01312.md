- **Falsification / acceptance**: collect exact build/config, menu state (0x04/0x09 vs selector 0x0A..0x0C), `views[0/1].fov`, eye poses and common tangent clip, source HWND/UV/aspect, copy predicate and array/mip/format, D3D11 debug-layer messages, full-extent per-slice GPU captures before Release, `xrEndFrame` result and same-build Quest3/VDXR L/R edge pixels.
