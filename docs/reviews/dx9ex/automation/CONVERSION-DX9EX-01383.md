Concrete **conditional** static interleaving, not a runtime reproduction: (a) old rank/rival tag T_old at pointer P with serial S exists but priority is not visited in partial walk W1; W1 snapshots C1 >= S and remains active; (b) another producer reuses P for a distinct new node and registers T_new with serial S+1 while W1 is ACTIVE, so both records may coexist; (c) W1 exits without consuming T_old; (d) full walk W2 snapshots C2 >= S+1, making BOTH eligible for pointer P. If the registry still lists T_old before T_new, ConsumeSpriteNodeScope(P) returns T_old (its old producer/Calc3D2D anchor) even though new node P is now live. Other tag removals can reorder the array and change which record wins: **misattribution is possible by source predicate, not deterministic or observed.** If P is re-registered only AFTER W1 exits, the active-cutoff guard is zero and replacement generally avoids this specific duplicate-entry interleaving. Reuse before a completed Present, producer concurrency, preserved older unvisited tag, current array order and a selected new physical node are all necessary for the proposed stale-owner case.
