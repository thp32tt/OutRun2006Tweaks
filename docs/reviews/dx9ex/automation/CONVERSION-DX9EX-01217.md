A delayed +TIME/GOAL batch must not inherit a sand particle fast path and a PMT CPU visibility result is not its GPU owner.
2. **Default compiled owner boundary (newly isolated).** `AGENTS.md:1-17` and `CMakeLists.txt:99-108,135-153,230-245` configure option-free builds with `OUTRUN_VR_R26_HUD_COMPARE=ON` and select `src/vr/d3d9/stereo_renderer_r30_r26_safe.cpp`; explicit R84 comparison with that flag OFF separately compiles R29-R33. The shipped R26+HUD `R30TryXyzrhwPrimitiveUP:3947-3990` computes distinct left/right transformed XYZRHW buffers and submits **two original physical `DrawPrimitiveUPHook` calls** through `R30ExecuteXyzrhwStereo:3829-3945`. This function has no DynamicVB ring branch. `src/vr/d3d9/stereo_renderer_r30.cpp:168-177,6478-6592` owns the *different, nondefault R84* particle-ring branch; `OUTRUN_VR_R30_PARTICLE_VB=1` is required and its value is cached at first evaluation. Therefore the presence of the optimization in the repository cannot establish R26+HUD particle upload savings or that a user package has it. This is a verified compilation/configuration **attribution boundary**, not a verified gameplay bug.
3. **R84 eligibility is narrow.** `src/vr/d3d9/r30_particle_upload_policy.hpp:6-59` demands opt-in, **exact** `WorldParticle`, `stereoWorld`, reliable effect-state snapshot, alpha enabled, depth write disabled, nonindexed, not recording a StateBlock, stride 16..256, >=3 vertices and 1 KiB..1 MiB per eye. `stereo_renderer_r30.cpp:6508-6531` derives the gate from actual `EffectiveScope`, state and reliable `R29OwnerTryGetEffectTelemetrySnapshot`. `WorldBillboard`, glass, water, lens, screen HUD, unknown alpha and **all indexed-UP draws** are not automatically eligible. This does not say how often the gate succeeds on a real sand-heavy frame.
4. **Ring transport and failure boundary are per-eye, not mono.** `src/vr/d3d9/r30_particle_dual_eye_ring.hpp:12-96` validates upload size, reserves one 4 MiB dynamic VB, packs separately transformed L/R bytes in one Lock/Unlock, uses DISCARD on wrap or NOOVERWRITE on append, binds each eye with separate offsets and finally nulls stream zero to match the UP side effect. `stereo_renderer_r30.cpp:6530-6592` uses a try-lock across prepare, both actual physical `R29OwnerCallRawDrawPrimitive` calls and restore; contention/prepare rejection keeps native bilateral UP. On first-eye stream-bind failure before physical draw it may return `E_NOTIMPL` only after successful stream reset. `MayUseNativeUpAfterGpuAttempt` forbids replay once **either eye** attempted a physical GPU draw (even if HRESULT failed), guarding alpha double-blend/partial-eye submission. Failed stream reset poisons/arms mono safety. `R30ExecuteXyzrhwStereo` handles RT/depth/viewport per-eye and `R30StateRestore::ResultAfterRestore` separately reports restoration failure. Dynamic VB success does not prove both eye pixels visible or improve FPS.
5. **Default R26+HUD bilateral baseline still has independent restore and reject gates.** In `stereo_renderer_r30_r26_safe.cpp:3829-3945,3947-3990,5349-5525`, invalid XYZRHW owner/transformation falls through `E_NOTIMPL` to guarded native/lower owner; admitted transformed draws attempt L and R separately. A right-eye/restore failure marks incomplete frame even when a left HRESULT is returned; no post-draw blind original replay. `R62TryFixedFunctionSpriteIndexed:5401-5442` is a fixed-function **indexed DIP** HUD path, not a WorldParticle nonindexed UP optimization or blanket D3DX batch fix. Distinguish a lower R29/original fallback from a physical mono diagnosis.
6. **Present and final headset evidence are different gates.** `src/vr/d3d9/stereo_renderer.cpp::PresentDestR9:692-811` requires world+duplicated+valid-pose stereo with no incomplete/right failure, then guarded DirectGPU/SBS/native Present before Frame.v2 publication. `vrhost/src/main_r23.cpp:2920-3008` independently selects a completed eligible producer frame; `main_r23.cpp:3555-3620` observes the final R24/R32-intercepted `xrEndFrame` layer/frame identity. Neither R84 opt-in nor R26 two-UP calls alone proves a specific sand draw's L/R final pixels, OpenXR timing or Quest3 comfort.
