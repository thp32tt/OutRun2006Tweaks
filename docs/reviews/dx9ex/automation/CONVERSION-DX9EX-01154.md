2. **Frame-budget state has process-static lifetime independent of the game's D3D resources.** `src/hooks_graphics.cpp:1513-1570` exposes a midhook at `Envmap_FaceCount_Addr=0x1447E` with **function-static** `pendingFaces`, `lastCounter`, `frequency`, `frameCadence`. The callback resets `lastCounter` and `frameCadence` when `VREnabled && VRNormalizeReflectionRate` is false, but does **not** clear `pendingFaces` on that branch; pending debt is updated on every callback. `src/vr/game/reflection_frame_budget.hpp:114-160` clears pending debt when `ReflectionUpdateRate=0`, caps normalized accumulated debt at 1.0, and limits an ordinary normalized face request to 3 / late-frame request to 2. These static values are not D3DPOOL resources; their presence does not itself prove an invalid texture, duplicated Draw, or visible stale reflection.

Neither inspected function calls `ReflectionUpdateRate::FaceCount_dest`, resets its statics, nor proves that the original game cubemap texture or its face cursor has been recreated. The **absence of a call in these handlers** is a local source fact, not an exhaustive claim about all original game Reset callbacks.
