## NEW_FINDING — confirmed static negative control, not a runtime pass

- **Verified:** In the normal *armed R13 overlay + seeded main stereo + active tracked query* branch, the R13 classifying owner intercepts the physical draw and executes it once in mono-shadow or (on failure) once on the original target while marking a gap. Therefore the R9-local query-skip success flag cannot be treated as evidence that this normal effective-owner path lost query content. This is distinct from 01279's untracked-Issue hook asymmetry, 01278's R7 right-stencil invalidation, and 01277's clear-generation sync.
- **Hypotheses only:** (A) overlay install failed/unready but R9 was seeded and an actually active physical query draw bypassed R13, allowing R9's local `true` skip to leave mono backup incomplete; (B) even when R13 is armed, moving a real query primitive from main RT to mono RT affects query sample or later main depth/stencil behavior. Neither A nor B is jointly supported by an actual game frame. Side-effect-free/read-only query draws, offscreen queries, frame poison, full subsequent clears and correct mono fallback can refute any visible defect.
