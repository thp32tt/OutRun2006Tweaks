3. **New precise asymmetry:** `src/hooks_uiscaling.cpp:3545-3580` takes one snapshot before native `End_hk.stdcall(self)`, invokes the real End under optional exact semantic, then unconditionally invokes `HudBatch.completeNativeEnd(submission)` on return **without passing HRESULT or comparing snapshot mutationSerial**. `src/vr/game/hud_command_batch.hpp:43-97` shows `completeNativeEnd` checks only non-null same sprite plus Begin generation and calls `end()` even if the ledger was changed within native End. In contrast `completeNativeFlush` requires `unchanged(previous)` (including mutationSerial) or invalidates, and `completeNativeDraw` inspects changed serial and admits only a clean last successful internal-Flush transition (`:99-142`).
4. Ledger evidence: `src/vr/game/hud_command_batch.hpp:177-239,242-267`: every `recordDraw` touches mutationSerial; `forget` touches it; a successful `Flush` forgets the previous commands and stamps `lastSuccessfulFlushMutationSerial`; `end` clears `active`, `boundaryReady` and provenance. Therefore the outer `End(G)` can erase the *evidence of intervening mutations of the same G/generation* before later diagnostics/semantic admission can distinguish whether they were the ordinary internal Flush or an unexpected reentrant draw. This is a **static observability/ownership boundary**, not proof a still-live native buffer was incorrectly discarded.
5. `src/hooks_uiscaling.cpp:3911-4090` snapshots before real Draw, checks `self == submission.sprite`, rechecks source/queue node/epoch after native Draw, uses `completeNativeDraw` and only rearms narrow queued Stage/GOAL boundaries. `src/hooks_uiscaling.cpp:3882-3907,4226-4255` sets the last queue-end Flush eligibility while the queue context exists. These strict predicates prevent labeling an arbitrary reentrant Draw as GOAL; an unproven one may run original-preserved.
6. The actual GPU consequences cannot be inferred solely from the End callback. `src/vr/d3d9/stereo_renderer_r33.cpp:1645-1755` preserves exact HUD draws as an original physical draw when proof fails rather than borrowing a world WVP; `src/vr/d3d9/stereo_renderer_r7.inc:1518-1559` only intentionally repeats a proven draw for L/R and restores RT/depth/viewport/WVP state; `...:1680-1744` separately evaluates Present success and stereo frame metadata; `vrhost/src/main_r23.cpp:1438-1513` renders separate D3D11 array layers 0/1; `...:3559-3599` executes and records real `xrEndFrame`.
