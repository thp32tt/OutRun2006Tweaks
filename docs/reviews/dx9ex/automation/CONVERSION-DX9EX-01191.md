## REVIEW_SCOPE — original producer → queue/semantic → original D3DX/native physical draw → R26+HUD R30/R62 left/right → restore → Present/OpenXR

1. **Producer identity is conditional, not a drawable fingerprint.** Historical original-EXE REA `docs/automation/OUTRUN_REA_RENDERING_ARCHITECTURE_20261018.md:5-20,62-67` identifies `0x00498670` and original type-0 `ID3DXSprite::Draw`/deferred Flush/End versus type-1 native `DrawPrimitiveUP`. `docs/automation/OUTRUN_VR_REA_RESOURCE_EVIDENCE_20261018.md:36-53,88-102` separates animation callers `0x9898E/0x98A36/0x98AC6`, numbers `0x989AD/0x98A10/0x98A89`, time/GOAL helpers and independent GOAL/result resources. These are static mappings, NOT observed per-fingerprint GPU draw samples. In this exact source, `src/hooks_uiscaling.cpp:379-395` correctly selects only **two** true +TIME sprani calls and all **three** numeric/print calls; `0x98AC6` is explicitly excluded as a mode-2 `0x2C006C` animation. The broad original resource list must NOT silently become a third +TIME hook.
2. **+TIME has a source-entry VR/queue-generation admission ticket.** `src/hooks_uiscaling.cpp:1661-1788` brackets all five exact E8 parents, snapshots VR enabled, queue-active state and queue epoch at entry, and requires `StageExtensionAdmission.mayPublish(...)` before registering newly appended nodes with `TagAppendedNodes`. Direct D3DX is split before source entry and conditionally flushed before exiting. Original runtime hook installation is atomic/rollback for the five (lines 2972-3015). This contract helps reject an earlier desktop/reentrant producer even if VR changes while the original E8 executes.
3. **GOAL/progress node registration has a different visible admission boundary.** The distinct `src/hooks_uiscaling.cpp::ResultProgressEnter/Leave:1536-1615` snapshots roots/tails/serial and protects *direct* D3DX with an entry-time `Settings::VREnabled` test, yet `ResultProgressLeave:1593-1596` calls `TagAppendedNodes` without the same entry/exit VR+queue epoch `StageExtensionAdmission` predicate. Separately, `::GoalTime_TagHelper:1858-1907` sets up a direct owner/Flush only conditionally but calls `TagAppendedNodes` after the original zero-argument `0xBE020/0xBE150` helper regardless of `Settings::VREnabled`. These are **confirmed source-level asymmetries**. The distinct full-parent `::ResultProgressFullParent:1619-1659` does check VR/state at entry and exit; it does not prove the two inner progress hooks or both GOAL helpers share that ticket. Do not claim this necessarily creates visible orphan glyphs: normal queue tagging while VR off, frame fences, hook activation lifetime and the game's own producer timing may make it benign.
4. **Registration protects root reachability but is not a source-enable validator.** `::TagAppendedNodes:1218-1295` uses a bounded, stable-root, previous-tail check for exact GOAL, result and +TIME producers and preserves newer exact tags. `src/vr/game/render_semantics.hpp::RegisterSpriteNodeScope:1576-1645` adds serialized producer/scope records, without independently testing the original source's VR/queue-admission ticket. `::SelectSpriteQueueNode:1789-1837` looks up exact tags and binds a new queue node epoch, which identifies the **consumer** selection, not the original source's entry epoch. `::EndSpriteQueueRender:1839-1863` deliberately retains unvisited tags; `::EndSpriteQueueFrame:1871-1899` retires tags at the explicit frame fence and Reset. These protections can prevent stale reuse but do not by themselves prove an *eligible source* generated a tag under a VR-toggle/reentrancy edge.
5. **Deferred D3DX physical ownership has an independent ledger.** `src/vr/game/hud_command_batch.hpp:16-47,74-141,177-277` records native Begin/Draw/Flush/End generations and mutation serials, the homogeneous producer, queued node/epoch, and special exact direct B9200 parent; it rejects mixed batches, failed Flush and unproven reentry. `src/vr/game/render_semantics.hpp:202-337` admits only exact `StageExtensionTime`, `GoalTime020/150`, `ResultProgress`, `OutRunStagePrintf` or proven `ResultTextB9200` to a finite HUD plane and suppresses *unproven direct physical D3DX* attribution. A sound queue tag is **not** evidence of a homogeneous deferred GPU batch, and a live direct source cannot certify older pending triangles. The original type-1 native UP must remain distinct from deferred type-0 D3DX.
6. **Crash boundary remains closed.** `src/hooks_uiscaling.cpp:396-412,3017-3035` keeps all 19 original B9200 result text E8 parents unmodified: minidump EIPs `0x97C5F` and `0x97E75` were inside displaced post-CALL branch bytes. Existing stack-proven glyph wrapper (`::TextGlyph_putSprite:2315-2358`) and fixed original zero-argument GOAL helper wrappers (`::GoalTime_TagHelper:1855-1909`) are distinct. No B9200 post-CALL/+5 hook, generalized text routine tag or result-number scaling should be inferred from this review.
7. **The actual final GPU/eye owner is still unmeasured.** In R26+HUD `src/vr/d3d9/stereo_renderer_r30_r26_safe.cpp::R30IsExactResultHudDraw:3073-3083` accepts exact physical semantic and valid queued node/epoch; `::R62TryFixedFunctionSpriteIndexed:5135-5310` additionally requires actual fixed-function `FVF 0x142`, null vertex shader, valid stereo pose and two-eye projection. `::DrawIndexedPrimitiveDestR30:5377-5461` tests independent ImGui then R62 and XYZRHW, falling back to R29/original; `::DrawPrimitiveUPDestR30:5464-5488` is a separate physical API. `::R30ExecuteXyzrhwStereo:3829-3927` handles physical L/R submissions, right RT/depth/viewport restore and failure poisoning. A logged `RESULT_HUD_REJECT` at lines 5411-5439 reports **R62_ONLY**, explicitly not the final route. Neither an admitted tag nor a rejection counter proves a GOAL physical draw went to the wrong eye.
8. **Presentation cannot prove that a specific glyph reached the HMD.** `src/vr/d3d9/stereo_renderer.cpp::PresentDestR9:676-814` checks frame-complete world/stereo/pose and the real Present status, and has mono/SBS/direct fallbacks; host `vrhost/src/main_r23.cpp::R23RenderProjection:1440-1513` renders L/R projection slices, with `::xrEndFrame:3562-3599` providing the final layer/frame boundary. No source-parent→queue node epoch→native Flush/physical DrawSerial + texture/VS/PS/RT → left/right HRESULT+restore → OpenXR submitted frame record was captured in this task.
