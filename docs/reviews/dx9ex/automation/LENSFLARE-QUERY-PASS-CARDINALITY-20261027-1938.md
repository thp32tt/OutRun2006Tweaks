For each `k < prim.draws[pass]` it binds the pass-specific draw record/shader/indices and calls `draw_indexed_primitive` at :1017. Multiple calls in one BEGIN/END do **not** establish stereo replay or duplicated visible sun pixels. All are colour-write-disabled in the normal `411420` wrapper.
