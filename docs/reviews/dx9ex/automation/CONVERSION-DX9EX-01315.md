Returning Draw compares live source and calls completeNativeDraw; a **clean** internal Flush is admitted as the first Draw of the next native batch, while unrelated mutations/reentrant Begin/source drift fail closed.
3. Queued +TIME/GOAL successor-node transition -> R64 BeforeQueueNode/BeforeQueueEnd -> R30/R62 actual D3D9 DIP or conservative XYZRHW/native route -> L/R render-target, depth, viewport and projection restoration -> R9 active stereo versus mono fallback at Present/Frame.v2 -> host selection / XR projection layers -> xrEndFrame. Do not interpret this as proof that D3DX legally permits Draw during End, that commands survive End, or that pixels are missing.
