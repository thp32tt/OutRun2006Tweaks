2. **Producer-to-native D3DX transition.** `src/hooks_uiscaling.cpp::VRProjectedD3DXSpriteIsolationR64::BeginDest/FlushDest/EndDest:3407-3508` snapshots original Begin generation and restores only a proven homogeneous direct +TIME/GOAL owner during the native Flush/End, maintaining original HRESULT and fail-closed unknown/mixed ownership. `::DrawDest:3824-3990` captures the source BEFORE original Draw, which may internally Flush on texture change; after native return it checks unchanged source, queued node/epoch and `HudBatch.completeNativeDraw`. `src/vr/game/hud_command_batch.hpp::Ledger::completeNativeDraw:82-141` only accepts a changed batch generation/mutation if a successful clean internal Flush cleared the prior batch; neither texture switch nor a positive semantic tag is an unconditional one-command/one-DIP guarantee.
3. **Actual R26+HUD physical fixed-function admission.** `src/vr/d3d9/stereo_renderer_r30_r26_safe.cpp::R30IsExactResultHudDraw:3073-3083` requires exact semantic with a valid live queue node+epoch for queued result content. `::R62TryFixedFunctionSpriteIndexed:5126-5352` requires game backbuffer and safe stereo base, corroborated HUD or projected source, triangle list, LIVE `GetVertexShader()==nullptr`, `GetFVF()==0x142`, stereo resources, nonempty live game viewport, latched nonzero pose sequence, valid eye affine, render state and finite original projection. It constructs per-eye projection matrices from original D3DX fixed-function projection; an unsupported or unproven candidate returns E_NOTIMPL. The `RESULT_HUD_EYES` sampled log contains producer/queue/pose/viewport/FVF and eye/restore results, but no explicit same-native-batch physical DrawSerial -> R9 pendingFrameId -> XR submitted frame tuple.
4. **R62 fallthrough is not final routing evidence.** `::DrawIndexedPrimitiveDestR30:5377-5461` handles independent external F11 ImGui first, then tries R62. Its `RESULT_HUD_REJECT` explicitly logs `stage=R62_ONLY finalRoute=UNDETERMINED` on E_NOTIMPL; the same physical DIP next tries XYZRHW then R30 screen-space/R29/original. Consequently an R62-only rejection does NOT prove a missing +TIME/GOAL eye. `::DrawPrimitiveUPDestR30:5464-5490` is the native-UP negative control, not a D3DX result indexed-quad counter.
5. **Two eyes and raster restore are separately gated.** `::R30ExecuteXyzrhwStereo:3829-3945` draws left; on success it switches right RT, depth/stencil and game viewport, draws right and calls `RestoreRightPassState`. Right-eye failure or failed restoration poisons the frame and arms safe fallback; the function can return the *left* HRESULT while independent flags record right failure. R62 additionally restores original PROJECTION after the pair (`:5285-5352`). `src/vr/d3d9/stereo_renderer_r22.cpp::R22SnapshotShadowedGameState/R22ReplayScope:283-408` captures or reuses a tracked game viewport/scissor snapshot and restores the original viewport via trampoline only after outer replay; `::R22StateBlockApplyDest:155-178` invalidates/refreshes the shadow at a reliable Apply boundary. This review does not repeat 01199's cached-disabled/unreliable Apply time window or claim the R22 scope wraps this exact sampled DIP without an observed call chain.
6. **Present fence is downstream of independently accepted frame.** `src/vr/d3d9/stereo_renderer.cpp::PresentDestR9:676-818` requires world-stereo proof, duplicated draw, pose/metadata and right/restore integrity, then chooses DirectGPU or SBS/fallback, forwards actual native Present and only publishes active stereo on a successful complete result. A successful result glyph DIP alone cannot set `FrameHadWorldStereo`. `src/vr/d3d9/stereo_renderer_r13.cpp::PresentDestR13:716-749` calls the lower Present and then `EndSpriteQueueFrame` for the R26+HUD compare macro, including overlay-not-ready, so the queue-frame retirement is NOT the per-glyph GPU DIP submission moment.
7. **OpenXR final consumer differs from game physical draw.** `vrhost/src/main_r23.cpp::R23RenderProjection:1440-1513` renders independently to left and right D3D11 XR swapchain array views from direct eye SRVs or split SBS UV halves and returns false on either eye rendering failure. `::xrEndFrame:3562-3599` submits the layer; host XR frame acceptance and identical optical positioning for the particular game glyph remain unproven without matching shared frame ID/pose and actual Quest3 headset evidence.
