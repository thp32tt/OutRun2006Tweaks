# HD UI 신규 이미지 생성 및 QA — 2026-10-13

1. **입력 검증:** `source/original_hd_dds/`의 영문 원본 DDS와 정확한 해시·캔버스·압축·투명 알파·방향 확인. 영어 읽기용 PNG는 원본으로부터 새로 변환하고 대응 해시를 기록한다. DDS 없는 참조 PNG는 새 DDS의 정본으로 승인하지 않는다.
2. **매핑:** `translations/OUTRUN_HD_FULL_TRANSLATION_MAPPING_20261013.csv`에서 `queue_index + source_dds_path + source_hash_key + english_source`를 확인한다. 기존 `translation_status`는 이미지 QA PASS가 아니다. 오역·오타는 제작 전에 재확인한다.
3. **ChatGPT 이미지 생성:** 원본 전체 화면과 투명 영역 유지. 영어·일본어 UI 문구만 한국어로 바꾸고 색·획·그림자·광택·기울기 방향·원본 글자 스타일을 최대한 따른다. 새로운 사각형, 버튼, 아이콘, 번호 또는 장식·배경 생성 금지. 번역 글자의 오자·가짜 자소 금지.
4. **보호:** 음악 제목, 차량명, 제조사, 브랜드, 로고와 텍스트 외 보호 아트는 원문/원본 그대로. 스테이지명은 음차와 의미를 문맥에 맞춰 통일.
5. **크기:** 원본의 글자/효과 허용 범위와 실제 UI 영역 초과, 잘림, 겹침, 알파 손상 FAIL. 단순히 번역문이 짧거나 글자 수·문장 전체 폭/높이·underfill이 다르다는 이유만으로 FAIL 금지. 각 글자는 native/75%/50% 획과 내부 공간 및 가독성으로 판정.
6. **DDS:** 원본 캔버스 크기·DDS 포맷·mipmap·방향과 투명 알파 보존. 합성 전후 비텍스트 원본 픽셀 보존 검증, 역변환 RAW/FLIPY 비교.
7. **기록:** 새 작업마다 원본 SHA, 문구, 생성 프롬프트/ID, 새 PNG/DDS SHA, 자체 QA와 독립 QA를 새로 기록. 이전 PASS/REWORK와 QC 이력 전부 무효. 게임을 실행하지 않았으면 `RUNTIME_VALIDATION=UNTESTED`.
8. **배포:** 기존 자동 컨트롤러/컨테이너 구성을 가져오지 않음. 새 이미지/테스트/배포는 개별 명시 후 시행.
