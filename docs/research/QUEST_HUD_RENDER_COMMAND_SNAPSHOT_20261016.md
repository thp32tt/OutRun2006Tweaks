## Phase 2: snapshot at the physical GPU sink (2026-10-16)
Add `GameSemantic::PhysicalDrawCommand`: immutable {scope, producer, queue node, node epoch, queued, exact lens-call epoch} copied once per real R33 D3D9 Draw. `R33Dispatch` now derives exact C993 lens owner from this snapshot instead of multiple independent TLS reads; preserves existing fail-closed original-WVP/alpha/StateBlock routing and stops inference based solely on textures or blend mode. Direct +TIME/GOAL remains owned by existing R64 `ScopedExactProducerSemantic` when the *real* D3DX Flush/End occurs. Nested sprite queue must outrank any direct source; regression verifies frame/queue transitions and lens isolation in `render_command_snapshot_smoke.cpp`. This is the command descriptor foundation; a complete renderer migration and user HMD sign-off remain untested.

### APK follow-up: exact lens invocation frozen in the physical command
The Quest native_pass -> per-eye projection -> sun_flare structure reinforced a source-command boundary already present in R84. The Windows C993 central sun now snapshots CurrentLensCentreCallEpoch together with scope/producer at the physical GPU primitive boundary. R30 raw-c64 ownership consumes that immutable epoch instead of rereading mutable TLS. A missing epoch fails closed to the original draw. This does not alter the independently correct CABE outer rings or enable speculative stage culling.
