# Dino 246 original-dimension HD cockpit — v1 implementation plan and verified scope

Date: 2026-11-06 KST

## Objective

Keep the original OutRun 2006 local game resources unchanged, and create a more detailed **external cockpit replacement** with a single steering wheel, realistic steering column, seat contours, gauge bezels, dash stitching, raised switches and a separate smooth gear lever. Respect the verified left-hand-drive coordinate basis of the original Dino `Cars/obj_plcar_dino_pmt.sz`.

## Actual original PC asset provenance and spatial anchors

Private, user-provided original game data was read on N100; the binary is **not** committed to GitHub. Source original PMT entry `obj_plcar_dino_pmt.sz`, 17 native objects, 41 embedded texture slots, original main car bounding box X `[-0.847,+0.847]`, Y `[0.126,1.117]`, Z `[-2.115,+2.156]`. Driver dashboard is approximately X `-0.32`, Y `0.7`, Z `-0.5`; seat centers about X `±0.34`. The model generator rejects unexpected source object counts/coordinate basis to prevent silent grotesque scaling errors.

## Notes on scope / integrity

- 123 independent replacement meshes, 17,080 vertices and 28,320 triangles in the locally generated v1.
- Materials: nine distinct textures; GLB 2048 px each, OVC 1024 px each (OVC format presently supports up to 2048 px and 112 MiB GPU payload).
- **Texture caveat:** all currently baked material textures are locally generated by deterministic PIL/Python algorithms, *not AI photo/diffusion-generated*. The user previously requested AI-generated artwork; that part remains pending and must not be described as complete.
- GLB is for Blender/preview. The OVC has passed the repository's actual R26 parser but has not been loaded by a running OutRun/Quest headset.
- The original game's dash and steering/seat geometry must be scoped out, or their coexistence will render duplicate cockpit parts. Do **not** simply replace the `.ovc` of a working FitV6 installation without a verified paired R26 test package.
- First visual comparison uses true source and generated geometry projected by CPU to a 2D preview. It is **not a real game screenshot**.
