## 추가 확인 사항

1. **확인된 것은 모드 소개/다운로드 페이지이고 사용자 테스트용 원본 파일 확보는 0건이다.** 검색만으로 원본 메시 상세 구조, 텍스처 해상도, 좌표 정합, 완성 운전석, Blender 가져오기 성공 및 OutRun OVC 파서 QA는 보증할 수 없다.
2. 게임 포맷: GTA V 자동차는 주로 `.yft`/텍스처 `.ytd`; [Sollumz](https://github.com/Sollumz/Sollumz/) + CodeWalker로 Blender 가져오기 가능(Blender 4.0+). Assetto Corsa는 `.kn5`; [KN5 Tools 공식 Blender 확장](https://extensions.blender.org/add-ons/kn5-blender-tools/)이 계층/재질/텍스처/노멀 보존을 지원하나 현재 확장 2.0.3은 Blender **5.0+** 필요(N100 기존 4.5.15와 불일치), 복잡한 AC/CSP 셰이더 재질은 수정 가능성 있다.
3. Need for Speed와 구형 GTA IV/SA 모델은 정확 차종 확보 보완용. 낮은 파일 용량이 실제 삼각형 수를 보증하지는 않지만 VR 운전석 고품질 충족 여부는 미확정. NFS Most Wanted는 별도 ModLoader 자산 형식/도구 경로 필요.
4. 저작자/업스트림 소유권: Forza·TDU·NFS Shift·CSR2 유래 파일을 제3자 모더가 무료로 공개했다고 해서 OutRun으로 다시 변환하거나 게임 모델과 함께 **재배포할 권리가 생기는 것은 아니다.** F430 Spider Nexus 및 Grotti Firenze의 명시적 변환 금지는 준수한다. 개인 모드 테스트 가능성도 개별 이용조건에 따라 다를 수 있다.
5. **추천 확인 순서:** F355 Spider, 360 Spider, 550 Barchetta, 512 BB 도로형, Dino 246 GTS → 나머지 13개. 우선순위는 '운전석 실재·충실도·외부 원본/라이선스·획득 난이도' 기준이며 변환 성공 보증이 아니다.
6. 웹에서 최신 확인은 2026-11-16. 오래된 등록일은 현재 모드 게시 상태에 대한 맥락이지 새 버전 의미가 아니다. 출처/사용허가는 재확인해야 한다.
